## 4. 환경변수

이 섹션은 원본 docx에 없는 내용이며, 사용자가 알려준 내용을 덧붙인 것이다.

### (1) 변수 이름

`.env`에 아래 두 환경변수가 있다.

| 변수 이름 | 용도 |
|---|---|
| DRDEASYDRUG_END_POINT | e약은요 서비스 호출 주소 |
| DRDEASYDRUG_API_KEY | 인증키(요청 변수 serviceKey에 쓰는 값) |

가정: 용도는 변수 이름과 이 문서의 요청 변수 설명에서 읽은 것이며 값으로 확인하지 않았다.

### (2) 확인 범위와 보관 원칙

- `.env`를 직접 읽지 않았다. 두 변수가 있다는 것은 사용자가 알려준 내용에 근거한다.
- 이 문서에는 변수 이름만 기록하고 값(주소 문자열, 키)은 적지 않는다.
- `.env`는 `.gitignore` 대상(`.env`, `.env.*`)이라 저장소에 올라가지 않는다.
- 코드에서는 환경변수로만 읽는다.

## 5. 원문 확인 필요 사항

원문의 오류로 보이는 부분은 지금 고치지 않고, 실제 API 응답값을 확인한 뒤 이 정리본을 수정할 예정이다.

### (1) 원문에서 어긋나 보이는 곳

| 번호 | 위치 | 내용 |
|---|---|---|
| 1 | 2장 (4) 요청/응답 메시지 예제, REST(URI) 요청 예시 | 예제 URI의 `trustEntpName`과 `startPage`는 2장 (2) 요청 메시지 명세에 없는 파라미터다. 명세에는 업체명이 `entpName`으로 되어 있고 `startPage`는 없다. |
| 2 | 2장 (4) 요청/응답 메시지 예제, 응답 메시지 | 예제 XML의 여는 태그와 닫는 태그가 맞지 않는다. `<efcyQesitm>`은 `</EFCY_QESITM>`로 닫히고, `<INTRC_QESITM>`은 `</efcyQesitm>`로 닫힌다. `<item>`을 닫는 `</item>`이 없고 `</items>`로 바로 닫힌다. |
| 3 | 2장 (3) 응답 메시지 명세와 (4) 응답 메시지 예제 | 응답 필드명(`efcyQesitm` 등 카멜 표기)과 예제 XML의 대문자 태그 표기(`EFCY_QESITM`, `USE_METHOD_QESITM`, `ATPN_WARN_QESITM`, `ATPN_QESITM`, `INTRC_QESITM`, `SE_QESITM`, `DEPOSIT_METHOD_QESITM`)가 다르다. |
| 4 | 1장 (1) 서비스 개요의 서비스 설명, 2장 (2) 요청 메시지 명세, 2장 (3) 응답 메시지 명세 | 서비스 설명은 문항1~6(효능, 사용법, 주의사항, 상호작용, 부작용, 보관법)이다. 명세에는 `atpnWarnQesitm`(문항3, 주의사항 경고)이 있고 `depositMethodQesitm`이 문항7(보관법)이라, 서비스 설명과 명세의 문항 번호가 한 칸씩 밀려 있다. |
| 5 | 2장 (3) 응답 메시지 명세의 `itemImage` 행 | 항목크기 칸에 `이미지`, 항목구분 칸에 `3000`이 들어 있다. 두 칸의 값이 뒤바뀐 듯하다. |
| 6 | 1장 (1) 서비스 개요의 서비스 WADL 운영환경 | URL이 `...DrbEasyDrugInfoService)?_wadl&type=xml`로 `)`가 붙어 있다. |
| 7 | 2장 (2) 요청 메시지 명세와 (3) 응답 메시지 명세의 샘플데이터(`efcyQesitm`, `atpnQesitm` 등) | 원문 표의 `?` 문자는 공백이 깨진 것으로 보이나 그대로 두었다. |
| 8 | 3장 OPEN API 에러코드 별 조치방안 | 원문에서 이미지였고, 이미지를 보고 표로 옮겼다. 코드와 문구를 원본과 대조해야 한다. |
