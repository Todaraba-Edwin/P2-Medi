## 1. 이슈
작업을 더 진행하기 전에 문서의 모호한 곳과 서로 충돌하는 곳을 점검하자는 사용자 요청(2026-11-07)으로 만든 점검 보고서의 후속 실행 티켓이다. 측정은 끝났고 이 티켓은 수정 실행과 도구 보강을 추적한다.

- **모호도(amb-v1)**: 전체 **0.50**(원값 0.487, 참조선 0.2). 이 값은 영역 간 순위를 보려는 상대 점수이고 절대값이 아니다. 정규화·정의를 고정한 뒤 코드 오류 수정만으로 0.615 → 0.487로 움직였다.
- **측정도구 검증**: 사람이 심은 12건 중 도구가 찾은 것 9/12(소표본). 충돌 후보 45건 중 **실제 충돌은 10건**(거짓 양성 약 78%).
- **완료 조건 측정 가능 비율**: A 영역(그래프·도구) 80/149, B 영역(하네스·안전) 15/40. "측정 가능"은 숫자나 확인 수단이 적혔다는 뜻일 뿐 실제로 잴 수 있다는 보장이 아니다.
- **모델이 찾은 충돌 13건(K1~K13)**: 높음 1·중간 6·낮음 6. 높음은 K1(하네스 세션 상태 대 PRD-07-01 A)이다.
- 점수는 순위용이고 도구는 판정기가 아니라 후보 목록을 만든다.

## 3. 점검 패키지
순서는 P1 → P2 → P3(RFP-35-02 A)이고 P4·P5는 가벼운 정정이다. 우선순위는 영역 모호도 × 핵심 가중치(RFP-35-01 A: A 0.20·B 0.20·C 0.25·D 0.15·E~H 각 0.05)이며 충돌 심각도로 순서를 정했다.

### 3.1 P1 하네스·안전(B)
- 하네스 세션 상태 정합: 서버는 요청마다 상태를 만들고 버리며, 기준 문서 `P2-doc/PJ2-PRD.md` PRD-07-01 A가 맞다. `PJ2-Agent-Harness.md`의 `thread_id` 서버 세션 서술을 요청 묶음 방식으로 고친다(K1).
- 음성 질문 응급 감지는 **서버 `guardrail_in` 한 곳**(RFP-35-03 A). 프론트는 키워드 목록을 갖지 않고 119 규칙 H4를 한 곳에서만 정의한다. `PJ2-PRD.md` S12 2행(전송 전 브라우저가 119를 띄움)을 맞춘다(K7).
- B 영역 완료 조건 40개 중 확인 수단이 없는 것에 테스트 이름·파일 경로·k/n 중 하나를 붙인다(RFP-12·RFP-33·AG-08).
