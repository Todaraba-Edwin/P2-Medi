# PRD-01 · PRD 정리

## 이슈
RFP 1~4장의 정의·목표·범위(포함/제외)를 저장소용 PRD 한 문서로 정리해, 이후 티켓과 README의 기준으로 쓴다. 특히 제외 범위(진단, 처방, 복용량 결정, 개인 의료기록, 대규모 전수 수집)를 명확히 한다.

## 완료 조건
- [ ] PRD 문서가 저장소에 있고 목표 4개, 포함/제외 표, 데이터 소스 3종, 평가 기준 4항목이 담겨 있다.
- [ ] 문서 내 모든 요구사항이 FR/NFR ID로 추적된다.

## 하위 작업
- [ ] RFP 1~5장 요약
- [ ] 포함/제외 범위 표 작성
- [ ] RFP-15 결정사항 반영

## 관련
- 선행: 없음
- 관련 문서: `P2-doc/PJ2-RFP.md` 1~5장

## 메모
- 가정: PRD 파일 위치는 `P2-doc/PRD.md`로 둔다(쓰기 범위 밖이므로 실제 작성은 별도 세션에서 한다).
