## 1. 이슈
RFP 11장 산출물 "아키텍처 문서". 8장 구조(입력 정리 `router` → 에이전트(ReAct) `model` ⇄ `tools`(공공 API Tool / 금기 조회 Tool / 근거 검색 3종) → Validator → 마무리, 응급 시 Guardrail이 119 고정 + 경로 병행. 노드 구성은 RFP-23-01의 6노드, 패턴 결정은 RFP-25)와 확정된 스택을 실제 구현 기준으로 설명한다. 프로젝트 성격(취업 포트폴리오, 목표는 Agent-RAG를 활용한 AX 경험)도 첫머리에 밝힌다.
