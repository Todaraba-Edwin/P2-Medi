## 1. 이슈
RFP 11장 산출물 "아키텍처 문서". 8장 구조(Router → 공공 API Tool / 금기 조회 Tool / Vector DB / 안내 전환 → 답변+출처 → Validator, 응급 시 Guardrail이 119 고정 + 경로 병행)와 확정된 스택을 실제 구현 기준으로 설명한다. 프로젝트 성격(취업 포트폴리오, 목표는 Agent-RAG를 활용한 AX 경험)도 첫머리에 밝힌다.

## 2. 완료 조건
- [ ] 문서 첫머리에 프로젝트 성격이 적혀 있다. 취업 포트폴리오이고, 핵심은 Agent-RAG 활용 AX 경험(Router·도구 선택·근거 고정·Validator·평가 수치)이며, 의약품 도메인은 소재다. Dr.DI는 가능성을 확인한 사례일 뿐 재현·성능 비교 대상이 아니고, 범위는 3주·1인 규모로 제어한다고 적혀 있다.
- [ ] 구조도에 금기 조회 Tool(적재 데이터, 성분코드 일치)과 응급 병행 흐름이 RFP 8장과 일치하게 그려져 있다.
- [ ] 문서에 LangGraph 노드 흐름도, 데이터 흐름(API/PDF), 스택 표, 환각 방지 장치 3종(근거 고정·검증·안전 응답)이 있다.
- [ ] 문서의 노드 이름이 실제 코드와 일치한다.
