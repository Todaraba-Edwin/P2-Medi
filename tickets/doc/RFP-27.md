## 1. 이슈
RFP 6장 FR-10(PRD-01-01, 2026-11-03): "되묻기: 약 이름이 모호하면(후보가 여럿이거나 확신이 낮으면) 후보 표와 질문 1개로 되묻고 가부는 말하지 않는다". AG-05·FE-02의 충족 여부를 추적한다. 평가 세트의 모호 20문항이 이 동작을 측정한다(PJ2-RFP.md 9.2절).

## 2. 완료 조건
- [ ] AG-05가 done이고 모호 판정(사전 후보 점수·후보 수) 테스트가 기록되어 있다.
- [ ] FE-02가 done이고 되묻기 카드가 후보 표와 질문 1개로 표시됨을 화면에서 확인했다.
- [ ] 모호 문항(예: "타이레놀 먹어도 돼요?")에서 후보가 정답 수만큼 나열되고 질문이 1개이며 가부를 말하지 않음을 평가 결과(AG-12)로 확인했다.

## 3. 하위 작업
- [ ] AG-05 모호 판정 확인
- [ ] FE-02 되묻기 카드 확인
- [ ] 모호 문항 평가 결과 확인
