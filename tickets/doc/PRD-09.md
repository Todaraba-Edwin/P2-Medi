## 1. 이슈
사용자 지적(2026-11-09): 근거 상세 패널에서 빨간 표지 **"삐! 임부금기 2등급"**과 회색 보조줄 **"슈도에페드린 · 2등급"**이 서로 다른 정보처럼 보인다. 사용자는 이를 "2단계"로 읽었다. 등급이 금기 종류 가운데 어디에 있는지, 임부일 때만 구분되는지를 설명하는 규칙이 필요하다. 그 설명은 이 티켓에 두고 해당 화면의 지시문(§7)을 함께 담는다.

- 사용자 지적 2(2026-11-09): ISSUE-001 화면에 "성분 중복: 아세트아미노펜이 두 제품에 모두 들어 있어요"가 나오는데, 첫 번째 약품(타이레놀콜드-에스정) 줄에는 아세트아미노펜이 보이지 않는다. DUR은 성분에 근거해 판정하므로 **주요 성분을 표기하고, 금기에 걸린 성분이 무엇인지 보이는 UI**로 개선해야 한다.
  - 사실: 판정은 성분 단위다(`check_contraindications`는 성분코드 목록을 입력으로 받고 성분 중복도 성분코드로 계산한다, RFP-22 §6·§7). 콜드-에스는 4성분이다(허가정보 주성분 fixture `ingredients_cold_s.json` `totalCount 4`: 아세트아미노펜·슈도에페드린염산염·덱스트로메토르판브롬화수소산염, 4번째는 `MAIN_INGR_ENG`상 Chlorpheniramine Maleate이고 한글명은 **미확인**(→ 2026-11-10 가정 해소: 허가정보·e약은요 스냅샷에 `클로르페니라민말레산염` 14건이 있어 표시명 `클로르페니라민`·염 `말레산염`으로 확정, [BE-10 §5](../backend/BE-10.md#5-메모)), 함량 `QNT`는 모두 `null`). 임부금기 CSV 행의 `성분명`은 원인 성분(`Pseudoephedrine`) 1개뿐이라 지금 보조줄에는 원인 성분만 보여 중복 줄과 어긋나 보인다. 성분 목록은 이미 `identify_drug`가 돌려주지만 응답 스키마와 화면에 실리지 않았다(mock `S1-core.json`의 `findings`에도 없음).

## 4. 금기 종류별 등급 유무

### 4.1 종류별 표
| 금기·주의 종류 | 등급 | 대신 있는 구조화 값 | 근거(직접 확인 2026-11-09) |
|---|---|---|---|
| **임부금기** | **있음: 1·2·M** | `금기등급`, `상세정보` | 임부금기 CSV 열 `…고시번호,금기등급,상세정보`. 값은 1(3,182행)·2(15,563행)·M(59행). API `getPwnmTabooInfoList02`의 `GRADE`(`1등급`) |
| 병용금기 | 없음 | 상대 성분, `금기사유` | 병용 JSON `metadata`, DUR 병용 CSV, API 필드(`P2-doc/PJ2-API-응답확인.md:72`) |
| 연령금기 | 없음 | `특정연령`·`특정연령단위`·`연령처리조건` | 연령금기 CSV 머리줄 |
| 용량주의 | 없음 | `1일 최대투여량` | 용량주의 CSV 머리줄 |
| 수유부주의 | 없음 | - | 수유부주의 CSV 머리줄 |
| 성분 중복 | 없음(코드가 계산한 결과) | 겹치는 성분 | RFP-22 §7 |

- **등급은 임부금기에만 있다.** 사용자가 임신 중(프로필·질문)일 때만 임부금기를 조회하므로, 화면에 등급이 나오는 경우도 **임부 확인 결과뿐이다.** 병용·연령·중복 표지에는 등급이 나올 수 없다.
- **등급은 제품 행에 하나다.** 임부금기 CSV는 제품코드마다 1행이다(18,804행 = 18,804제품, 등급이 둘 이상인 제품 0개). 복합제는 행의 `성분명`이 등급의 원인 성분을 적는다. 예: 타이레놀콜드-에스정은 4성분 제품이지만 행의 성분명은 `Pseudoephedrine`, 등급 2다.
- **같은 등급이 출처 두 곳에서 온다.** 파일(제품 행, `금기등급`)과 성분정보 API(성분 단위, `GRADE`). 보통 같지만, 다르면 한쪽을 확정하지 않고 둘 다 보인다(PRD 15장 `P2-doc/PJ2-PRD.md:301`, RFP 5.1절 (7)).

### 4.2 등급은 단계가 아니다
- **"단계"가 아니라 "등급"이다.** 데이터·고시 모두 "등급"이라 부른다(고시 제3조 제3호). (PRD-09-02)
- 1과 2는 위험의 높고 낮음을 매기는 단계가 아니다. **둘 다 "원칙적으로 사용금지"이고, 2등급에만 예외 단서가 있다**(`P2-doc/MFDS_병용금기_지정규정_고시.md:74-75`).
- M은 고시에 없고 심평원 「기능과 역할」이 "상병에 따른 1등급 또는 2등급"이라고 설명한다(RFP-17 §6.4, M 처리 규칙 §7.2).

## 6. 표기 규칙
확정은 결정 PRD-09-01~04에 따른다(괄호 안 번호). 나머지는 위 사실에서 바로 나오는 제안이다.

| ID | 규칙 |
|---|---|
| G1 | **등급은 한 줄(한 항목)에 한 번만** 쓴다. 표지에 쓰고, 보조줄에는 반복하지 않는다(PRD-09-01) |
| G2 | 등급은 **항상 "임부금기 N등급"**으로 쓴다. "2등급"만 단독으로 쓰지 않는다 |
| G3 | 화면·응답에서 **"단계" 대신 "등급"**만 쓴다(PRD-09-02) |
| G4 | 병용·연령·용량·수유부·성분 중복 표지에는 등급을 쓰지 않는다. 연령은 `특정연령`(예: "연령금기 · 만 N세 미만" 형식, 원문 값)을 쓴다 |
| G5 | **임부 배지 안에서** 1·2·M은 같은 색·같은 "삐!" 표지다. 2등급을 덜 위험한 색(주황 등)으로 보이지 않는다(등급 조사 H24). 임부 배지와 병용 배지의 색이 서로 다른 것은 G14가 정하며 G5와 충돌하지 않는다 |
| G6 | M은 1이나 2로 바꾸지 않는다. "임부금기 M등급" + 보조 문구는 심평원 설명 인용(PRD-09-03) |
| G7 | 등급의 뜻은 근거 상세에 **고시 원문 그대로**(1·2) 또는 심평원 설명과 판·표·쪽(M)을 코드가 넣는다. LLM 의역 금지(등급 조사 H23, PRD-09-04) |
| G8 | 파일과 API의 등급이 다르면 **출처를 붙여 둘 다** 보인다(예: "파일: 임부금기 2등급 · 성분 API: 임부금기 1등급"). 출처 없는 등급 두 개를 나란히 두지 않는다 |
| G9 | 요약 문장에서 등급을 근거로 복용 가부를 말하지 않는다("2등급이라 괜찮아요" 금지). 기존 H2·H5와 등급 조사 H24 |
| G10 | 제품 줄마다 **주성분 전체를 한글명으로** 보인다. 출처는 `identify_drug` 성분 목록(허가정보 주성분)이다. 성분명으로만 식별한 약(H17)은 그 성분 하나만 보인다(PRD-09-05) |
| G11 | 성분 칩에 상태를 **글자로** 붙인다. 금기 원인 성분은 `금기 원인`(경고색), 중복 성분은 `중복`(주의색), 나머지는 표시 없음이다. 색만으로 구분하지 않는다(접근성). 등급은 칩에 쓰지 않고 제품 표지에만 쓴다(G1과 같음) |
| G12 | 성분이 5개 이상이면 `금기 원인`·`중복` 칩을 먼저 두고 나머지는 `외 N개`로 접는다(종합감기약은 9성분까지 있음) |
| G13 | 함량(mg)은 결과 카드와 요약에 쓰지 않는다. 요약의 용량 숫자 금지(RFP-21-03)와 혼동을 피하기 위해서다. 근거 상세에 넣을지는 PRD-09-06이다 |
| G14 | **금기 종류마다 배지를 따로 둔다**(PRD-09-07 A). 병용금기 = 기존 경고 빨강, 임부금기 = 별도 색(보라/자주 계열, PRD-09-08 A). 한 질문에서 병용·임부가 둘 다 해당하면 **배지 두 개가 나란히** 나온다. 같은 종류 안에서는 해당 항목마다 한 개다. 배지 순서(병용→임부 등)는 FE-02에서 정한다. 모든 종류의 배지는 "삐!"를 쓰는 경고 표지의 성격(눈에 띄는 경고 표시)을 유지하고, 임부 색도 "안전" 신호로 읽히지 않아야 한다. 색 값(hex)은 지금 확정하지 않고 FE-02 구현 때 대비비 4.5:1 확인으로 정한다. 연령금기 배지의 색은 이 결정 밖이며 FE-02에서 정한다 |
| G15 | **색만으로 종류를 구분하지 않는다.** 모든 배지에 종류를 말하는 글자가 반드시 있다("삐! 병용금기" / "삐! 임부금기 N등급"). G11(상태는 글자로도 표시)과 같은 원칙이며 색각이 다른 사용자와 흑백 화면에서도 종류가 구분된다. 아이콘 모양을 종류별로 달리하는 보강(PRD-09-07 C)은 FE 구현 단계에서 선택할 수 있다 |

## 7. 화면 지시문
FE 구현(FE-02 근거 상세, FE-01 결과 카드)과 mock fixture에 그대로 쓴다. 문구는 코드 상수다.

### 7.1 결과 카드
왼쪽 "금기 확인 결과 · 임신 기준".

```
타이레놀콜드-에스정                         [⚠ 삐! 임부금기 2등급]
주성분  [슈도에페드린 · 금기 원인] [아세트아미노펜 · 중복] [덱스트로메토르판] [클로르페니라민]
근거: 임부금기 고시

타이레놀정500밀리그램                       [임부금기 목록에 없음]
주성분  [아세트아미노펜 · 중복]
안전하다는 뜻은 아니에요

두 제품 함께                                 [성분 중복]
아세트아미노펜이 두 제품에 모두 들어 있어요
```
- 표지 = `삐! 임부금기 {grade}등급`(M이면 `삐! 임부금기 M등급`).
- 주성분 칩 줄 = `주성분 [{표시명} · {상태}] …`(G10~G12, PRD-09-05). 그 아래 `근거: 임부금기 고시`. **등급은 표지에만 둔다.**
- 칩의 성분명은 염 이름을 줄인 표시명이다(예: 슈도에페드린염산염 → 슈도에페드린). 원문 염 이름과 성분코드는 근거 상세(§7.2)에 둔다. 줄이는 규칙은 사전(BE-10)이 정하고 화면은 그 표시명을 쓴다. 위 예의 4번째 성분 한글명은 미확인이라 확정 표시명이 아니다.
- 병용금기는 두 제품의 원인 성분 칩 양쪽에 `병용금기 원인`을 붙이고, 줄 아래에 `{성분A} + {성분B}`를 적고, 그 아래 보조줄에 `사유: {금기사유 원문}`(원문 그대로, 2줄 말줄임, 용량 숫자가 걸리면 서버가 뺌, 서버 칸 `Finding.reasons`)을 적는다(§7.4와 일치, FE-02-06 A).
- "목록에 없음" 항목은 그대로 둔다(`임부금기 목록에 없음` + "안전하다는 뜻은 아니에요").

### 7.2 근거 상세
오른쪽 "판정 · 임부금기".

```
타이레놀콜드-에스정                        [⚠ 삐! 임부금기 2등급]
주성분  [슈도에페드린 · 금기 원인] [아세트아미노펜 · 중복] [덱스트로메토르판] [클로르페니라민]
        성분코드·원문 염 이름(작은 글씨): 슈도에페드린염산염 254000ATB · …
고시 20200061(2020-07-10)
상세정보 "임부에 대한 안전성 미확립."
▸ 임부금기 2등급이란?
    고시 원문: "사람에서 태아에 대한 위해성이 나타날 수 있으며, … 원칙적으로 사용금지.
    다만, … 예외로 한다."
    출처: 「의약품 병용금기 성분 등의 지정에 관한 규정」 제3조 제3호 나목 · 기준일 2026-07-21
```
- 현재 보조줄 `슈도에페드린 · 2등급` → **성분 칩 줄**로 바꾸고, 성분코드·원문 염 이름은 칩 아래 작은 글씨로 둔다(PRD-09-05). 등급은 표지에만 둔다. 함량은 PRD-09-06 결정 전까지 쓰지 않는다.
- "임부금기 N등급이란?" 접힘 블록은 L1 청크 ID로 코퍼스 원문을 읽어 렌더한다(PRD-09-04). 펼치기 전 기본은 접힘이다. 표지·고정 문구 영역을 가리지 않는다(PRD 15.4 금기 발견 행).
- 파일·API가 같으면 한 줄로 `파일·성분 API 일치`라고 적는다. 다르면 G8 형식의 두 줄로 쓴다.

### 7.3 M 등급
```
메토트렉세이트정 …                          [⚠ 삐! 임부금기 M등급]
주성분  [메토트렉세이트 · 금기 원인] · 적응증에 따라 등급이 달라요
상세정보(원문) "1등급: 류마티스성 관절염 및 건선 / 2등급: 항암치료"
▸ 임부금기 M등급이란?
    "상병에 따른 1등급 또는 2등급 여부에 따라 처방·조제 사유 기재"
    출처: 건강보험심사평가원 「기능과 역할」 2026년판 표4.3-5, 인쇄 638쪽
```
- 적응증을 모르면 등급을 고르지 않는다(RFP-17 §7.2 3번). "처방·조제 사유 코드 M"과 섞지 않는다.

### 7.4 다른 금기 표지
등급이 없는 종류다. 임부금기 표지(`삐! 임부금기 N등급`)는 보라/자주 계열이고(G14), 아래 표는 병용·연령·중복이다. 병용·임부가 모두 해당하면 두 표지가 한 줄에 나란히 나온다.

| 종류 | 표지 | 보조줄 |
|---|---|---|
| 병용금기 | `삐! 병용금기`(경고 빨강) | `{성분A} + {성분B} · 사유: {금기사유 원문}` |
| 연령금기 | `삐! 연령금기`(색은 FE-02에서 정함) | `{특정연령}{특정연령단위} {연령처리조건} · 원문 값` |
| 성분 중복 | `성분 중복`(주의색, "삐!" 아님. PRD-06-03 범위 확인) | `{성분}이 두 제품에 모두 들어 있어요` |

### 7.5 mock과 화면 시험
- `evaluation/mock_gen/m1_chat.py`가 만드는 근거 상세 문구를 위 형식으로 맞추고, 화면 시험용 fixture에 **파일≠API 등급**과 **M** 사례를 하나씩 둔다.
- 화면 시험(FE): ① 한 항목 안에서 "등급" 글자가 표지 밖에 나오지 않는다 ② 등급 없는 종류의 표지에 "등급"이 없다 ③ "단계" 글자가 화면에 없다 ④ 1·2·M 표지의 색이 같다 ⑤ 중복 줄에 나온 성분이 해당 두 제품의 칩에 모두 보인다 ⑥ 금기 원인 칩이 표지 등급의 원인 성분과 일치한다 ⑦ 상태는 글자로도 표시된다 ⑧ 병용·임부가 동시에 해당하면 배지 2개가 나란히 보인다 ⑨ 임부 배지 색이 병용 배지와 구분되고 임부 1·2·M은 같은 색이다(색 값의 대비비 4.5:1 확인 포함). 모든 배지에 종류 글자가 있다(G15).
