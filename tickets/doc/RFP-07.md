## 1. 이슈
RFP 6장 FR-06: "Guardrail: 진단·처방 금지 문구, 응급 키워드가 있으면 119 안내를 맨 위에 고정하되 금기 조회는 막지 않음, 범위 외 거절. 조회 결과에 금기가 없어도 안전하다고 말하지 않는 고정 문구와 '근처 약국·약사에게 확인' 안내를 모든 답변에 코드로 붙인다". AG-08의 충족 여부를 추적한다. 응급 안내에 119와 약국·약사 외의 지침을 넣을지는 RFP-19의 공식 출처 확인 결과를 따른다.

## 2. 완료 조건
- [ ] AG-08이 done이다.
- [ ] 진단·처방 요청, 응급 키워드, 범위 외 질문 각각에 대한 응답 결과가 기록되어 있다.
- [ ] 응급 키워드 질문에서 119 안내가 응답 맨 위에 있고 금기 조회 결과도 함께 나옴을 확인했다.
- [ ] 금기가 조회되지 않은 질문의 응답에 "안전하다는 뜻이 아님" 고정 문구와 약국·약사 확인 안내가 코드로 붙음을 확인했다.
- [ ] RFP-19 결과 밖의 응급 지침·연락처가 응답에 없음을 확인했다.
- [ ] 응급 병행 흐름이 RFP 8장 구조도(Guardrail이 119 고정, 위 경로는 막지 않고 병행)와 일치하고, 응급 키워드 감지가 AG-08 한 곳에만 있음을 확인했다.

## 3. 하위 작업

- [ ] 8장 구조도와 응급 병행 비교, 키워드 감지 위치 확인
