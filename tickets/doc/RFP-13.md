## 이슈
RFP 7장 고지: 화면·응답에 "공공데이터 기반 정보 제공이며 진단·처방이 아님"을 표시하고, 사용한 자료의 출처와 기준일을 함께 표시한다. 한국의약품안전관리원 파일 데이터는 공공저작물 제2유형(출처표시, 상업적 이용금지)이므로 출처를 밝히고 상업적으로 이용하지 않는다. 화면(FE-02)과 응답(AG-08)이 모두 충족해야 한다.

## 완료 조건
- [ ] FE-02, AG-08이 done이다.
- [ ] 화면과 API 응답 본문 양쪽에 고지 문구("공공데이터 기반 정보 제공이며 진단·처방이 아님", "금기 목록에 없다는 것이 안전하다는 뜻이 아님", "요양기관의 DUR 점검을 대체하지 않음")가 있음을 확인했다.
- [ ] 파일 데이터를 쓴 답변과 화면에 출처(한국의약품안전관리원)와 기준일(2026-07-21)이 표시됨을 확인했다.
- [ ] 이용 조건(공공저작물 제2유형: 출처표시, 상업적 이용금지)을 확인했고, 출처를 밝히며 상업적으로 이용하지 않음이 README(PRD-04)에 적혀 있다.
