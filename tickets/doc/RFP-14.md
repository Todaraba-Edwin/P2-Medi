## 이슈
RFP 12장 리스크 9건의 대응이 실제 반영됐는지 확인한다.
1. API 키 발급·호출 제한 → 1주차 첫날 발급, 응답 캐싱 (BE-01, BE-02, BE-03)
2. HWP·복잡한 표 파싱 실패 → PDF 우선, 실패 문서 제외 (BE-04)
3. e약은요 상호작용은 문장형 → 병용금기 판정은 DUR 기준 (AG-05, BE-03)
4. DUR 금기 데이터를 확보하지 못함 → OpenAPI·파일 데이터·고시 PDF 세 경로로 확보하고 기준일 표시 (RFP-17)
5. 텍스트 레이어가 없는 이미지 PDF → OCR로 필요한 쪽만 읽고 불가능하면 범위에서 제외 (BE-04)
6. 고시 PDF의 표가 쪽마다 다르게 추출됨 → 파서 시험 전에는 구조화된 파일·API 우선 (BE-04, RFP-15)
7. 파일 데이터와 고시는 갱신되지 않는 스냅샷 → 답변에 기준일 표시, API 교차 점검 (AG-06, FE-02)
8. 금기등급 M은 고시에 없고 심평원 문서에만 정의됨 → 심평원 설명 인용, 등급은 상세정보 원문 (RFP-17)
9. 일정 지연 → FR-07 등 권장 항목부터 축소 (RFP-08)

가정: 4~8번의 담당 티켓은 각 대응의 내용에서 읽어 붙인 것이며, RFP 12장에 담당 티켓이 적혀 있는지는 확인하지 않았다.
