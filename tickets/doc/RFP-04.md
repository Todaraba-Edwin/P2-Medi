  - RFP-04-02 A 해석: FR-03 "표를 마크다운으로 보존해 파싱"은 **마크다운 원본 표를 파싱해 "행 + 표 제목·열 이름 반복" 청크로 보존**하면 충족으로 본다. 근거는 `P2-doc/PJ2-DUR-RAG-근거설계.md:97`(5장 (2) L1 별표 "표 한 행 + 열 이름 반복", 결정 12)이고, 위 확인(별표 행 3,091/3,091, 허가 표 1,445/1,445)이 증거다.
  - RFP-04-01 A 구현: `ChunkFilter`에 `years`·`issuers`를 더했다(`backend/app/agent/tools/corpus.py`). 원격 `build_where`는 강한 필터가 있을 때만 `year = ANY`·`issuer = ANY`를 함께 건다(약한 필터 규칙 유지). `year`가 빈 청크는 연도 필터에서 **제외**된다(`notice_no`·`base_date`와 같은 규칙, `test_year_filter_excludes_empty_year`). 실데이터 연도 2026 후보 37,943 = 전체 스캔, 부처 2종 후보 = 전체 스캔.
  - 남은 일: `year` 칸이 없는 로컬 30,744청크(l1_notice 2,904·l3_eyak 27,840, 빌드 코드가 연도를 채우기 전 파일)는 고치지 않았다. 유도 규칙은 `year = base_date 앞 4자리`(모두 2026, `chunk_id`는 본문 해시라 바뀌지 않음)이다. 로컬 재생성과 원격 UPDATE는 승인 뒤 메인이 한다.
  - RFP-04-03 A: `backend/tests/test_ag05_followup.py`의 간헐 실패를 시험에서 trace id·시계를 고정해 없앴다(같은 시험 30회 반복 실패 4 → 0, 코드 동작 변경 없음).
