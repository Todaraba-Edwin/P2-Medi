## 1. 이슈
RFP 6장 FR-05: "Validator: 답변이 원본 API·문서와 일치하는지 점검 후 출력". 구현 티켓 [AG-07](../agent/AG-07.md)의 충족 여부를 추적한다.

## 2. FR-05 조건별 대조

### 2.1 대조 방법과 범위
- 기준일은 2026-11-19이고 대상은 develop 브랜치다. 코드와 시험 파일을 **읽기만** 했고 pytest는 돌리지 않았다. "시험"은 시험이 존재한다는 뜻이며 통과 기록은 [AG-07 §2](../agent/AG-07.md#2-완료-조건)를 따른다.
- FR = Functional Requirement(기능 요구사항). FR-05 문장은 `P2-doc/PJ2-RFP.md` 6장 표(`:317`)에 한 줄로 있다: "Validator: 답변이 원본 API·문서와 일치하는지 점검 후 출력". 이 문장이 요구하는 동작을 네 조건으로 나눠 대조했다(가정: 나누는 기준은 이 문서의 해석이다).
- Validator는 LLM 답변 문장을 **출구에서 코드로 검사**한다. 판정기(LLM)는 기본 꺼짐이다(`backend/app/agent/validator.py:3-5`).
- 상태·체크박스·결정 표는 바꾸지 않는다. 체크 제안은 §2.5에 적는다.

### 2.3 검사 항목과 처리 표
`validator.py:40-59`의 검사 이름과 `CHECK_ACTIONS`(`:79-98`)를 그대로 옮겼다. 처리는 `DROPPED`(그 문장만 삭제, 남은 문장이 있으면 `FIXED`)와 `REWIND`(답변 단위 되감기, 상태 `FAIL`)뿐이다.

| 번호 | 검사 이름 | 무엇을 막나 | 처리 |
|---|---|---|---|
| ① | `SAFE_ASSERTION` | "안전합니다" 같은 안전 단정 | 삭제 |
| ② | `DOSE_CHANGE_OR_BYPASS` | 복용 변경·중단·복용 지시, 의료진 우회(허가사항 원문 인용 구간은 제외) | 삭제 |
| ③ | `GRADE_VALUE_INVALID` | 1·2·M 밖의 등급 값(H22) | 삭제 |
| ④ | `M_NO_DETAIL`·`M_CONVERTED` | M 등급 상세 원문 없음, M을 1·2등급으로 환산(H22) | 삭제 |
| ⑤ | `FILE_API_CLAIM` | 파일/API 한쪽만으로 확정하는 문장 | 삭제 |
| ⑥ | `MISSING_ADVICE_ABSENT`·`MISSING_IMPLIES_NONE` | 미확보 항목에 약사 확인 권고가 없음 / 미확보를 "없음·안전"으로 암시 | 되감기 / 삭제 |
| ⑦ | `BAD_CLAIM_TYPE` | `claim_type`이 없거나 모르는 값 | 삭제 |
| ⑧ | `NUMBER_NOT_IN_EVIDENCE` | 근거에 없는 연령·등급·번호·날짜 | 삭제 |
| ⑨ | `QUOTE_MISMATCH` | 인용부호 안 글자가 원문과 다름(H28) | 삭제 |
| ⑩ | `GRADE_EXCEPTION_MISUSE` | 등급 예외 단서를 복용 허용 근거로 쓴 문장(H24) | 삭제 |
| ⑪ | `UNCONFIRMED_AS_FACT` | 확인하지 못한 항목만 인용한 사실 문장 | 삭제 |
| ⑫ | `REFERENCE_AS_VERDICT` | 참고 전용·코드 미연결·미식별 항목으로 금기 여부를 확정 | 삭제 |
| ⑬ | `SOURCE_KIND_MISSING` | 출처 종류가 없는 판정 항목 인용(H29) | 삭제 |
| ⑭ | `CLAIM_LAYER_NOT_ALLOWED` | 금기 여부를 말하면서 판정 항목(L0)을 인용하지 않음 | 삭제(개선, 기본 꺼짐) |
| ⑮ | `INGREDIENT_NOT_IN_EVIDENCE` | 근거 원문에 없는 성분명 주장 | 삭제(개선, 기본 꺼짐) |
| ⑯ | `CLAIM_OMITTED` | 핵심 금기 FOUND 항목을 인용한 문장이 없음 | 되감기(개선, 기본 꺼짐) |

- 문장 필터(`sentence_filter`, H1)가 근거 ID 없음·용량 숫자·진단 단정을 먼저 거르고, Validator는 그 나머지만 본다(`validator.py:7-12`, 이중 처리 금지). 그래프 호출 순서는 `graph/nodes.py:194`(필터) → `:199`(`validate`)다.
- 고정 문구 상수는 검사 전에 문장에서 지운다(`validator.py:341-344` `strip_fixed`, `test_ag07_validator.py:85`·`:335`).
