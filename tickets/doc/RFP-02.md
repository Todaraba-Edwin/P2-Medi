## 1. 이슈
RFP 6장 FR-01: "Router(입력 정리): 질문에서 약품명·연령·임신 여부·질환 등 엔티티를 추출하고 모호 여부와 질문 유형을 판정해 상태에 기록한다. 경로(도구)는 Router가 정하지 않고 에이전트(ReAct)가 고른다(RFP-25-02). 연령·임신 여부는 대화 중 입력하거나 사용자가 동의해 저장한 프로필(FR-09)에서 가져온다. 질문·대화 내용은 저장하지 않는다". 구현 티켓(AG-05)이 이 요구를 충족했는지 추적한다.

## 2. 완료 조건
- [ ] AG-05가 done이고, 엔티티 추출·모호 판정·유형 라벨 기록 테스트 결과가 기록되어 있다.
- [ ] 도구 선택은 `model`(ReAct)이 하고(공공 API Tool / 금기 조회 Tool / 근거 검색 3종), Router는 경로를 정하지 않음과 응급 병행(Guardrail이 119 고정, 경로는 막지 않음)이 RFP 8장 구조도 설명·8.2절과 일치함을 확인했다.
- [ ] 게스트로 쓸 때 추출한 연령·임신 여부와 질문·대화 내용이 DB·파일·로그에 남지 않음을 확인했다.
- [ ] 프로필을 사용하는 경우(확장, BE-11을 한 경우만) 저장 범위가 사용자가 동의한 프로필 항목뿐이고 질문·대화 내용은 저장되지 않음을 확인했다.
