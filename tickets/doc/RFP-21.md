## 이슈
PJ2-W1 구현을 시작하기 전에 e약은요·DUR 품목정보·DUR 성분정보에 2026-11-01 승인된 의약품 허가정보를 더한 4종을 실제로 호출해, 이 프로젝트를 실제 공공 API로 진행할 수 있는지 확인한다. 결과는 RFP 5.2절에 기록하고 서비스별 응답은 `P2-doc/PJ2-API-응답확인.md`에 둔다. 근거는 RFP 10장 사전 행("공공 API 4종 실측 확인(RFP-21)")이다. 2026-11-02 정리: 처음 3종이던 범위를 허가정보 API 승인으로 4종(오퍼레이션 총 20개, 목 픽스처 12건)으로 넓혔고, 페르소나 3명으로 8.1 흐름을 통과시킨 기록까지 이 티켓에 있다. 2026-11-01 사용자 요청: API 테스트 상황을 Pre-Week에서 확인하고 RFP-번호 문서로 PJ2-RFP.md에 기록한다.

## 페르소나와 결과물 (가설 검증)

> 2026-11-01 작성. 인물은 **가상의 시험용 페르소나**이고, 약 이름·코드·문장·건수는 모두 이번에 실제 API 4종과 `data/` 파일에서 확인한 값이다. 이 절은 진단·처방이 아니며, 서비스가 만들어 낼 수 있는 결과물의 모양을 실제 데이터로 시험한 것이다. 추측한 부분은 "추정"으로 표시했다.

### 가설과 실제 데이터
사용자 가설: "타이레놀과 병용이 금지되는 사례가 유아·임산부에게 있다." 먼저 데이터에 그런 사례가 있는지 확인했다.

| 확인한 것 | 결과 | 출처 |
|---|---|---|
| 아세트아미노펜 **단일제**(타이레놀정 500mg, 8시간, 산, 어린이 현탁액 등)의 병용금기 | **없다.** KIDS 병용금기 쌍 0개, 성분정보 API(`D000147`) 0건, 품목정보 API 0건 | KIDS 병용금기 JSON, DUR 성분정보·품목정보 API |
| 병용금기가 있는 타이레놀 제품 | **`타이레놀콜드-에스정`(복합제) 하나.** 상대는 항파킨슨제 3종: 사피나미드(고시 20250086), 라사길린(20250046), 셀레길린(20250046) | KIDS 병용금기 JSON |
| 성분 단위 API의 같은 금기 | 덱스트로메토르판 × 라사길린·셀레길린 "경련, 반사항진, 이상고열, 혼수 등", 슈도에페드린 × 셀레길린 "고혈압, 빈맥 유발" | DUR 성분정보 `getUsjntTabooInfoList02` |
| 품목정보 API로 콜드-에스정(`202106954`) 조회 | 병용·임부·연령·효능군중복·용량 **모두 0건** (복합제를 성분으로 풀지 않는다) | DUR 품목정보 API |
| **결론** | 병용금기가 실제로 걸리는 사람은 유아·임산부가 아니라 **항파킨슨제를 먹는 사람**이다. 유아·임산부에게 걸리는 것은 병용금기가 아니라 **제품 연령, 임부금기, 성분 중복, 라벨 문장**이다 | |

그래서 페르소나는 유아(P1), 임산부(P2)에 더해, 병용금기가 실제로 걸리는 사례를 보여 줄 P3를 추가했다.

### 결과물 2 유아 응답: 제품 연령과 성분 중복

- 쓰는 자료: e약은요 라벨 문장(L3), DUR 품목정보 `MATERIAL_NAME`, DUR 성분정보 효능군중복, KIDS 용량주의 CSV(L0)

> **[요약]** 줘도 되는지는 정해 드릴 수 없습니다. 확인된 내용은 아래와 같습니다.
> 1. 타이레놀콜드-에스정은 허가사항에 "만 15세 이상"이 복용하는 약으로 적혀 있어, 만 2세는 대상이 아닙니다.
> 2. 두 약에 모두 아세트아미노펜이 들어 있어 같은 성분을 중복해 먹게 됩니다. 어린이타이레놀현탁액 허가사항에도 "아세트아미노펜을 포함한 해열진통제와 함께 복용하지 마십시오"라고 적혀 있습니다.
> 3. 아이에게 줄 양은 이 서비스가 정할 수 없습니다. 허가사항에는 "연령대별 권장용량은 허가사항을 참고하십시오"라고 되어 있으니 근처 약국·약사에게 확인해 주세요.

### 결과물 5 성분 연결표
복합제를 어떻게 풀어야 하는지 보여 주는 근거 상세(펼침)용 표다. 콜드-에스정 하나가 데이터마다 다르게 나타난다.

| 구성 성분 | DUR 성분코드(API) | KIDS 파일에서 보이는 모양 | 이번에 걸린 규칙 |
|---|---|---|---|
| 아세트아미노펜 | `D000147` | 병용금기 JSON은 복합제를 **하나의 성분코드 `254000ATB`**로 묶는다 | 용량주의 기준 4,000mg(KIDS), 효능군 해열진통소염제 |
| 슈도에페드린 | `D000448` | 임부금기 CSV는 `Pseudoephedrine`으로 **풀려 있다** | 임부금기 2등급 |
| 덱스트로메토르판 | `D000200` | 위 `254000ATB` 안에 포함 | 라사길린·셀레길린과 병용금기 |
| 클로르페니라민 | 병용금기 목록에 없어 이번에 코드를 확인하지 못함 | 연령금기 CSV에 클로르페니라민 복합제 31행(12세 미만, 호흡억제)이 있으나 콜드-에스정 행은 없음 | 확인하지 못함 |

- 시사점: KIDS는 복합제를 한 덩어리로, API는 성분으로 푼다. 제품명 → 성분코드 매핑(BE-10)은 복합제를 성분으로 풀어야 하고, 이것이 사용자 결정 ②(파일↔API 성분 연결 규칙)의 구체적 근거다.

### 결정 2 파일과 API의 성분 연결 규칙 미결정
아직 논의하지 않았다. 지금까지의 근거만 모아 둔다.
- 영문 성분명 정규화 일치: 임부 64%, 병용 36%. 품목 `EDI_CODE`: 표본 8개 중 4개.
- **API 안에서는 M-코드로 이어진다**: 품목정보 `MAIN_INGR`(`[M040353]`)와 허가정보 주성분 상세 `MTRAL_CODE`가 성분정보 `ORI_INGR`에 들어 있다(6개 중 4개 일치. 어린이 타이레놀 2개는 같은 이름의 다른 M-코드라 이름 보조). KIDS 파일과의 연결은 여전히 이름이나 `EDI_CODE`가 필요하다.
- KIDS는 복합제를 한 덩어리로, API는 성분으로 푼다([결과물 5](#결과물-5-성분-연결표)).

### 결정 3 허가사항 용법용량 표 인용 여부 미결정
허가정보 API 승인으로 새로 생긴 결정이다. 어린이타이레놀현탁액의 허가사항 용법용량에는 연령·체중별 1회 권장용량 표가 있다(예: "만 2~3세 12 ~ 15.9kg 160mg 5mL").
- **A안(권장)**: 용량 숫자를 인용하지 않는다. "허가사항의 용법용량을 확인하세요"와 출처 안내만 한다. CLAUDE.md 1장의 "복용 여부와 용량은 정해 주지 않는다"와 결과물의 "만들 수 없는 것"(체중별 용량)과 맞는다.
- **B안**: 허가사항 표를 원문 그대로 인용한다. 일반인이 용량 판단 근거로 쓸 위험이 있고, Validator의 "용량 숫자 없음" 규칙(AG-07)을 예외로 둬야 한다.
- **영향**: 어느 쪽이든 수집 자체는 같다. 정하기 전까지 응답 예시(결과물 2)는 A안 기준이다.
