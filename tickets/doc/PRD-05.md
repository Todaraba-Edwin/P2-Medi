## 1. 이슈
RFP 11장 "발표 자료 (`MediAgent 포트폴리오 발표.pdf`)". `P2-doc/`에 같은 이름의 PDF가 이미 있으나, 최종 수치와 데모가 반영됐는지는 확인되지 않았다.

## 2. 완료 조건
- [ ] 발표 자료에 PRD-03의 전후 수치와 한계가 반영되어 있다.
- [ ] 파일명이 정해져 있다: 기존 `MediAgent 포트폴리오 발표.pdf` 또는 표시 이름을 반영한 `Can I PPiyak 포트폴리오 발표.pdf`(PRD-06 §4.5가 이 티켓에서 정하도록 넘김). 정하면 RFP 11장·RFP-16 표기도 같은 작업에서 맞춘다.
- [ ] 발표 자료에 수요 근거(Dr.DI 등은 수요 확인 사례이며 복제·성능 수치 비교가 아님)와 프로젝트 성격(취업 포트폴리오, 목표 = Agent-RAG 활용 AX 경험)이 적혀 있다.

## 3. 하위 작업
- [ ] 기존 PDF 내용 검토
- [ ] 최종 수치·데모 캡처 반영
- [ ] 수요 근거·포트폴리오 성격 쪽 반영 (RFP 1장 기준)

## 4. 관련
- 선행: PRD-03, FE-03
- 관련 문서: `P2-doc/MediAgent 포트폴리오 발표.pdf`

## 5. 메모
- 가정: 기존 PDF는 초안으로 보고 done 처리하지 않는다.
- 발표 자료 3쪽(범위 "보건사업 자격 요건 안내", 데이터 "건강검진·보건사업 지침")과 4쪽(비정형 문서 "보건소 만성질환·지원 사업 안내서")은 초기 작성 잔재라 RFP에서 제거했다(2026-10-31 사용자 확인). 최종 발표 자료에서도 고친다.
- 2026-10-31 발표 자료 7쪽 예시 질문 중 암검진 질문은 국가건강검진 범위 제거로 쓰지 않는다. 최종 발표 자료에서는 일반인 대상 의약품 병용금기 질문(예: 임산부·아동에게 상비약을 먹이기 전 확인)으로 바꾼다.
