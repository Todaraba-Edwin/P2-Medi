## 이슈
RFP 5장 e약은요(제품명·성분·효능·주의사항)를 Tool로 호출한다. 6장 FR-02의 "조회 시각 기록"과 12장 "응답 캐싱"을 함께 구현한다.

## 완료 조건
- [ ] 제품명 입력 시 품목기준코드(`itemSeq`)·효능·사용법·주의사항·상호작용 필드가 포함된 결과가 반환된다. e약은요 응답에는 성분 필드가 없으므로 성분은 DUR 품목정보와 `itemSeq`로 연결한다(`P2-doc/PJ2-API-응답확인.md`).
- [ ] 결과에 조회 시각(ISO 8601)이 포함된다.
- [ ] 같은 요청 2회째는 캐시에서 응답하고, 호출 제한 오류 시 명확한 오류 객체를 반환한다.
- [ ] 단위 테스트가 통과한다.
- [ ] 효능·사용법(사용 연령 포함)·경고·주의사항·상호작용·부작용 문장형 필드가 원문 그대로 상태에 보존된다(제품 라벨 문장 인용과 retrieval의 원천, `P2-doc/PJ2-가설검증.md` TC-01, H16).

## 메모
- 가정: 캐시는 파일 또는 SQLite 기반으로 시작한다.
- RFP-17 이관(2026-10-30): e약은요 활용신청·키 확인과 응답 샘플로 정리본(P2-doc/IROS_239_e약은요_서비스_v1.0.md) 5장의 원문 오류 검증은 이 티켓에서 한다. 환경변수는 DRDEASYDRUG_END_POINT, DRDEASYDRUG_API_KEY.
- 2026-10-31 사용자 진술: 활용신청을 마쳤고 키는 .env에 기록했다(값은 읽지 않았다). 키 동작 검증은 추후 한다.
- 2026-10-31 확인 필요: 메토트렉세이트정·알렌드로네이트 같은 전문의약품 제품이 e약은요에서 조회되는지 응답 샘플로 확인한다. 조회되지 않으면 라벨 문장 근거가 없어 `P2-doc/PJ2-가설검증.md` 8.2의 허가정보 원문 후보 검토가 필요하다.
- 2026-10-31 추가: 전체 품목 1회 수집과 스냅샷 저장, 전문의약품 포함 여부의 전수 기록은 BE-12가 맡는다(선행: 이 티켓). 이 티켓은 런타임 Tool, 캐시, 조회 시각을 맡는다.
- 2026-11-01 응답 확인: e약은요는 필드 14개, 전체 4,746건, 성분 필드 없음, 전문의약품 0건(메토트렉세이트·알렌드로네이트·포사맥스·마빌·엠티엑스·메토젝트·포사맥스플러스). 앞선 "전문의약품이 e약은요에서 조회되는지 확인"은 답이 나왔다: 조회되지 않는다. 라벨 문장이 필요하면 허가정보 API 활용신청을 사용자가 결정한다(RFP-15). 근거: `P2-doc/PJ2-API-응답확인.md` 3장.
- 2026-11-01 정리본 5장 검증 결과는 `P2-doc/IROS_239_e약은요_서비스_v1.0.md` 5장 (3)에 있다. 이 티켓의 다른 완료 조건(클라이언트·캐시·조회 시각·테스트)은 구현 전이다.
