## 이슈
RFP 5장 DUR(병용·연령·임부 금기)을 Tool로 호출한다. 12장에 따라 병용금기 판정은 e약은요 상호작용 문장이 아니라 DUR 기준으로 한다.

## 완료 조건
- [ ] 약품 2개 입력 시 병용금기 여부와 사유가 반환된다.
- [ ] 연령·임부 금기 조회가 각각 동작한다.
- [ ] 결과에 조회 시각이 포함되고 캐시를 사용한다.
- [ ] 단위 테스트가 통과한다.

## 하위 작업
- [ ] 엔드포인트별 클라이언트
- [ ] 캐시·조회 시각
- [ ] 테스트
- [ ] 포털 활용신청과 키 확인 (RFP-17에서 이관)
- [ ] 특정연령대금기 포함 응답 샘플로 필드와 오퍼레이션 경로명 확인 (RFP-17에서 이관)
- [ ] DUR OpenAPI 명세서 수령 뒤 documents-writer로 정리 (RFP-17에서 이관)
