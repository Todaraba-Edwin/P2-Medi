## 이슈
RFP 5장 DUR(병용·연령·임부 금기)을 Tool로 호출한다. 12장에 따라 병용금기 판정은 e약은요 상호작용 문장이 아니라 DUR 기준으로 한다.

## 완료 조건
- [ ] 약품 2개 입력 시 병용금기 여부와 사유가 반환된다.
- [ ] 연령·임부 금기 조회가 각각 동작한다.
- [ ] 결과에 조회 시각이 포함되고 캐시를 사용한다.
- [ ] 단위 테스트가 통과한다.

## 하위 작업
- [ ] 엔드포인트별 클라이언트
- [ ] (확장, 권장) DUR 중복(성분·효능군)·용량·투여기간 주의 오퍼레이션 호출 시험. 핵심(병용·연령·임부 금기)의 완료 조건을 채운 뒤에 하며, 일정이 모자라면 먼저 줄인다 (RFP 4장 확장 범위)
- [ ] (확장, 조건부) 수유부 주의 오퍼레이션이 있으면 호출 시험. 존재 확인과 포함 결정은 RFP-19에서 한다
- [ ] 캐시·조회 시각
- [ ] 테스트
- [x] 포털 활용신청과 키 발급, .env 기록 — 2026-10-31 사용자 진술(품목정보·성분정보 환경변수 기록). 키 동작 검증은 아래 응답 샘플 확인에서 한다 (RFP-17에서 이관)
- [ ] 특정연령대금기 포함 응답 샘플로 필드와 오퍼레이션 경로명 확인 (RFP-17에서 이관) — 키 동작 검증 포함, 추후
- [ ] DUR OpenAPI 명세서 수령 뒤 documents-writer로 정리 (RFP-17에서 이관)

## 메모
- RFP-17 결정(2026-10-30): 식약처 DUR OpenAPI 클라이언트로 특정연령대금기 오퍼레이션을 포함한다. 환경변수는 DURPrdlstInfoService03_END_POINT, DURPrdlstInfoService03_API_KEY(성분정보는 DURIrdntInfoService03_*)를 쓴다. 활용신청·키 확인, 응답 샘플로 필드와 오퍼레이션 경로명 확인, 명세서 정리는 RFP-17에서 이관되었다(하위 작업 참고).
- 2026-10-31 사용자 진술: 활용신청을 마쳤고 키는 .env에 기록했다(값은 읽지 않았다). 키 동작 검증은 추후 한다.
