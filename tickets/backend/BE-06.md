# BE-06 · 채팅 API 엔드포인트

## 이슈
질문을 받아 LangGraph를 실행하고 답변·출처·조회 시각·고지를 JSON으로 반환하는 FastAPI 엔드포인트가 필요하다. 프론트와 평가 스크립트가 이 응답 형식을 공유한다.

## 완료 조건
- [ ] `POST /chat`이 질문을 받아 `answer`, `citations[]`(출처·조회 시각·조항), `disclaimer`, `route` 필드를 반환한다.
- [ ] 빈 질문·과도한 길이 입력에 4xx를 반환한다.
- [ ] 엔드포인트 테스트가 통과한다.
