- 2026-11-01: 키 두 항목과 `.env.example`을 체크했다. 남은 것은 프로젝트 골격·설정 모듈과 `uvicorn` 기동 후 `/health`다. 프로브(`backend/scripts/api_probe/`)의 `/health`는 200이지만 BE-01의 골격이 아니므로 체크하지 않았다.
- 2026-11-02: 백엔드 배포 대상으로 AWS 무료 인스턴스 1대를 고려 중이다(RFP-15-06). 환경변수는 `.env` 외에 배포 환경의 비밀 관리 방식도 RFP-15-06에서 정한다.
- 2026-11-04: 사용자가 Supabase 프로젝트를 만들고(서울, 자동 RLS 켬) 변수 이름을 알려 주었다. `.env.example`에 이름만 추가한다: `SUPABASE_DB_URL`(Session pooler, 핵심 경로), `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SECRET_KEY`, `SUPABASE_JWKS_URL`(뒤 넷은 BE-11 로그인용). 환경변수는 API 8 + LLM 키 3 + Supabase 5 = 16개다. DB 비밀번호는 `SUPABASE_DB_URL`에 포함해 두고 별도 변수는 두지 않는다(사용자, 2026-11-04).
- 2026-11-05 (RFP-32): 개발 중 LLM 호출 절감용 record/replay 캐시 `evaluation/mock_gen/llm_cache.py`가 있다(키=제공자·모델·messages·인자·프롬프트 파일 해시, `LLM_CACHE=off|record|replay` 기본 off, 평가 실행 `MEDIAGENT_EVAL=1`이면 강제 off). 이 티켓의 개발 하네스에서 **`gpt-6-luna` 호출에 연결**하고 평가 측정에서는 끄는 규칙을 테스트로 고정한다.
- 2026-11-05 점검: 이 티켓에 골격·`/health`, 개발 하네스(RFP-29-01), `gpt-6-luna` 호출 확인(RFP-15 이관), LLM 호출 캐시 연결(RFP-32)이 쌓여 W1 첫 티켓으로 크다. 나누는 안: BE-01(골격·`/health`) / 개발 하네스·호출 확인(새 티켓). 사용자 확인 대기(`schedule.md` Recap 8번).
