## 이슈
파싱된 문서를 청킹하고 메타데이터(문서종류·연도·부처, 조항/쪽 위치)를 붙여 Vector DB에 적재한다. FR-03 필터 검색과 FR-04 조항 표기의 기반이다.

## 완료 조건
- [ ] 적재 스크립트 한 번 실행으로 컬렉션이 만들어진다(재실행 시 중복 없음).
- [ ] 각 청크에 문서종류·연도·부처·원문 위치(쪽/조항) 메타데이터가 있다.
- [ ] 표는 한 청크 안에서 끊기지 않거나, 끊길 때 헤더가 반복된다.

## 하위 작업
- [ ] 청킹 규칙
- [ ] 메타데이터 스키마
- [ ] 적재 스크립트
