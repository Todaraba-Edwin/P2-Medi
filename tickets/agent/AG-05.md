## 1. 이슈
> **2026-11-03 RFP-25-02 A로 역할을 정정했다**: Router는 **입력 정리**(엔티티 추출·모호 판정·유형 라벨 기록)만 한다. 아래의 \"분기\"·\"경로\" 표현은 이 정정 전 문구가 남은 것이므로 **경로 선택은 `model`(ReAct)이 한다**로 읽는다.

RFP FR-01: 질문에서 약품명·연령·임신 여부·질환 등 엔티티를 추출하고(연령·임신 여부는 대화 중 입력하거나 사용자가 동의해 저장한 프로필에서 가져오며, 질문·대화 내용은 저장하지 않는다) 질문 유형 라벨과 모호 여부를 상태에 기록한다. 경로(공공 API Tool / 금기 조회 Tool / 문서 검색 / 안내 전환)는 Router가 아니라 `model`(ReAct)이 고른다(8장 구조도의 기본 경로, RFP-25-02). 병용·연령·임부 금기 질문은 유형 라벨 `contraindication`으로 기록하고, `model`이 금기 조회 도구(성분코드 정확 일치)를 호출한다(8장, 12장).

응급 키워드 감지는 Router가 하지 않는다. AG-08(Guardrail)의 코드 규칙 한 곳에서만 감지하고, Router는 상태의 `emergency` 병행 신호를 읽기만 한다. 응급 신호가 있어도 `model`은 평소처럼 도구를 고른다(금기 조회를 막지 않는다).

규칙 구현 방식은 항목마다 (코드) / (프롬프트)로 표기한다.
