## 이슈
RFP FR-08: 검색 결과가 없으면 지어내지 않고 모른다고 응답한다. "금기 목록에 없음"(조회했고 금기가 나오지 않음)과 "근거 없음"(약 미식별·데이터 없음)을 구분해 안내한다. LLM 내부 지식으로 채우지 않고, 확인 가능한 안내(근처 약국·약사)로 연결한다.

규칙 구현 방식은 항목마다 (코드) / (프롬프트)로 표기한다.

## 완료 조건
- [ ] (코드) API·금기 조회·문서 검색 모두 0건인 질문에서 "확인할 수 없다"는 응답이 나오고 사실 문장이 없다.
- [ ] (코드) 약품명을 성분코드로 바꾸지 못한 경우(약 미식별)는 "근거 없음"으로 분류되고 "찾을 수 없는 약이라 확인하지 못했다"는 안내가 나온다. 이 경우 금기가 없다는 말을 하지 않는다.
- [ ] (코드) 약은 식별됐고 조회도 했지만 금기가 나오지 않은 경우는 "금기 목록에 없음"으로 분류되고, "안전하다는 뜻이 아님" 고정 문구(AG-08)와 함께 나온다. 두 경우의 응답 문구가 서로 다름을 테스트로 확인했다.
- [ ] (프롬프트 + 코드 분류) 일부 근거만 있을 때는 있는 부분만 답하고 없는 부분은 없다고 밝힌다. 여러 약 중 일부만 식별된 경우 식별된 쌍만 답하고 나머지는 근거 없음으로 밝힌다.
- [ ] (코드) 안내 문구는 "근처 약국·약사에게 확인"으로 통일되어 있고 "의사"나 "공식 사이트" 같은 다른 안내 문구가 없다.
- [ ] 테스트가 통과한다.
- [ ] 응급 질문에 약 이름이 없으면 119 안내를 유지한 채 약 이름을 묻는다(`P2-doc/PJ2-가설검증.md` TC-11).
- [ ] (코드) 재검색 보정(RFP 5.1절 (3) 역할 D): 결과가 0개이거나 점수 미달이면 재작성한 질의(영문 성분명, 효능군 일반화)로 재검색하고, 재검색 상한(기본 1회, AG-04 세트로 조정)을 넘으면 "근거 없음"으로 분류한다.
