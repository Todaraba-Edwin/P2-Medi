## 1. 이슈
RFP FR-08: 검색 결과가 없으면 지어내지 않고 모른다고 응답한다. "금기 목록에 없음"(조회했고 금기가 나오지 않음)과 "근거 없음"(약 미식별·데이터 없음)을 구분해 안내한다. LLM 내부 지식으로 채우지 않고, 확인 가능한 안내(근처 약국·약사)로 연결한다.

규칙 구현 방식은 항목마다 (코드) / (프롬프트)로 표기한다.
