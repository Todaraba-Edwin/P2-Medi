## 1. 이슈
AG-04가 평가 세트(개발셋 150·시험셋 151)를 만들었고, 사람 검수는 이 티켓에서 닫는다. 검수 도구는 `evaluation/eval_set/review_tool.py`(`export`·`apply`, 커밋 15582c7)이고 **담당은 사용자**다. 문항의 15~20%를 사람이 검수해 오류 비율을 기록하는 것은 PJ2-RFP.md 9.2절과 RFP-28-04의 조건이며, 골든 문항과 불량 답 견본은 사람이 정답·답을 직접 확인한다. AG-11 기준선 측정 전에 끝나야 한다.

시험셋은 정답 확인만 하고 개선에 쓰지 않는다(RFP-26-04, PJ2-RFP.md 9.1절 8번). 결정 대기는 없다.

## 2. 완료 조건
- [ ] 골든 11문항(시험셋)이 `golden_verified=true`다. 확인: `apply` 뒤 시험셋 jsonl에서 `golden_verified`가 true인 문항을 세어 11이다.
- [ ] 검수 표본 52문항(개발셋 26 + 시험셋 26)의 판정(OK/ERROR)과 오류 내용이 `human_review.status`·`human_review.error_found`에 반영되어 있다.
- [ ] 불량 답 견본 9개(개발 4 + 시험 5)를 사람이 다시 쓰거나 확인했고 jsonl의 불량 답 text에 반영되어 있다.
- [ ] 오류 비율(ERROR 수 / 검수 표본 수)을 k/n으로 `메모`에 기록했다(PJ2-RFP.md 9.2절, RFP-28-04 사람 검수 15~20%).
- [ ] `apply`로 `manifest.json`의 sha256이 갱신되었고 `evaluation/eval_set/test_build.py`가 통과한다.
- [ ] 검수 시작 뒤 `build_eval_set.py`를 다시 실행하지 않았다(재빌드는 검수 결과를 지운다).
- [ ] 시험셋 문항을 개선(프롬프트·노드 수정)에 쓰지 않았다(RFP-26-04).
