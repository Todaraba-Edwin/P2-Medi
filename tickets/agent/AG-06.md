## 이슈
검색·조회된 근거만 사용해 답변을 만들고, 모든 답변에 출처·조회 시각(또는 자료 기준일)·조항을 붙인다. LLM은 설명과 종합만 맡는다(RFP 1장).

## 완료 조건
- [ ] 생성 프롬프트가 제공된 근거만 사용하도록 제한되어 있다.
- [ ] 모든 사실 문장에 연결된 출처 ID가 있다.
- [ ] API 출처에는 조회 시각이, 파일 데이터와 문서 출처에는 자료 기준일과 문서명·조항/쪽이 포함된다.
- [ ] 샘플 10건에서 출처 누락이 0건이다.

## 하위 작업
- [ ] 근거 고정 프롬프트
- [ ] 출처 매핑
- [ ] 샘플 점검
