## 1. 이슈
BE-14가 구현한 사진 약 이름 추출을 Pre-Week 시험과 같은 4장·같은 검수 정답으로 다시 재서, 시험 때 수치(확대 상품명 34/51, 사전 후보 포함 35/51)와 비교하는 **보조 기록**이다(확장, 권장). PJ2-RFP.md 9장의 지표·평가 세트는 바꾸지 않으며, 사진 변환은 그래프 앞의 함수라 9장 지표에 들어오지 않는다(RFP-33-05 A와 같은 방식, PRD-08 §11). 소표본이라 k/n과 Wilson 95% 구간으로만 보고하고 유의성을 주장하지 않는다(9.1절).

일정이 모자라면 확장이라 **가장 먼저 줄인다**(PRD-08-07 A).

## 2. 완료 조건
- [ ] (PRD-08-07) BE-14 구현물(`/ingest/image` 또는 같은 함수)로 같은 4장·원본/긴 변 1400px 확대 두 조건을 3회 반복해, 시험 스크립트(`scripts/mock/vision_pouch_test.py`)와 검수 정답(`mock/vision_test/labels_user_reviewed.json`, 로컬)을 이어받아 채점했다.
- [ ] 상품명 일치와 사전 후보(top-5) 포함을 k/n으로 적고 Wilson 95% 구간을 병기했다. Pre-Week 수치(확대 34/51, 사전 후보 포함 35/51)와 나란히 보였다.
- [ ] 환각(정답에 없는 실존 제품명)과 `high` 확신도 오답 건수를 적었다.
- [ ] 개인정보 유출 0건을 확인했다(환자 이름·병원·약국·연락처가 출력·로그에 없음, 사람 확인 건수 기록).
- [ ] 확인 전 판정 도구 차단(H19)의 단위 테스트가 통과한다(AG-01과 짝, 평가 지표가 아니라 방어선 확인).
- [ ] 결과를 보조 기록으로 남겼고 PJ2-RFP.md 9장 지표·세트·목표는 바꾸지 않았다. 9.4절 보조 지표에 올리지 않는다.
- [ ] 개인정보가 있는 사진 원본과 검수 정답 파일은 커밋하지 않았다(로컬 전용).
- [ ] 호출 비용이 개발 비용 원장(RFP-34-05)에 기록되어 있다.
