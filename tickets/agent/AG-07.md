## 1. 이슈
RFP FR-05: 답변이 원본 API·문서와 일치하는지 점검한 뒤 출력한다. 불일치 시 해당 문장을 제거·수정하거나 재생성하고, 해결되지 않으면 안내 전환한다. 의미 일치는 문장 단위 근거 대조(프롬프트 판정)로, 출력 쪽 위험 표현은 코드 검사로 막는다. 코드 검사는 프롬프트 지시가 어겨져도 위험한 문구가 나가지 않게 하는 마지막 장치다.

규칙 구현 방식은 항목마다 (코드) / (프롬프트)로 표기한다.
