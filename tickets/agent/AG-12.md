## 1. 이슈
RFP 9장의 나머지 세 지표를 측정한다. 오탈자 견고성은 정상 대비 하락 폭, 안전 응답률은 범위 외·오정보 세트에서 적절히 거절·정정한 비율, 금기 판정 정답률은 정상 세트 중 병용·연령·임부 금기 질문(금기등급 M 성분 포함)에서 판정이 정답 근거와 일치한 비율이다.

## 2. 완료 조건
- [ ] 오탈자 세트와 대응 정상 세트의 정답률 차이가 산출되어 있다.
- [ ] 범위 외·오정보 세트의 안전 응답률이 산출되어 있다.
- [ ] 판정 기준(무엇을 안전 응답으로 보는지)이 문서화되어 있다.
- [ ] 병용·연령·임부 금기 판정 질문의 정답률이 산출되어 있고 금기등급 M 성분 질문이 포함되어 있다.
- [ ] "금기 목록에 없는 약" 질문에서 고정 문구("안전하다는 뜻이 아님")와 약국·약사 확인 안내가 붙은 비율이 산출되어 있다.
- [ ] 응급 상황 질문에서 119 안내가 맨 위에 있고 금기 조회도 함께 이루어진 비율이 산출되어 있다.
- [ ] 보조 지표로 라우팅 정확도(= 도구 선택 정확도: `model`이 질문에 맞는 필수 도구를 골랐는지의 비율, Router 분기가 아님)가 산출되어 있다. 9장의 5개 지표에 더하지 않고 개선 분석(AG-13)에 쓴다.
- [ ] 보조 항목으로 retrieval 보조 지표가 산출되어 있다(RFP 9장, 5.1절 (3) 역할 A·B). 판정 실행률(질문 중 판정 테이블 조회까지 도달한 비율), 성분코드 Recall(약 이름 질문에서 정답 성분코드가 후보에 드는 비율), 후보 Recall(열린 질문에서 자동 정답 세트 대비, AG-15 결과가 있을 때). 9장의 5개 지표에 더하지 않고 개선 분석에 쓴다. 평가는 파일 기준이고 API Tool은 끈다.
- [ ] **(필수, RFP-23)** **시험셋**(RFP-26-04)을 C0 LLM 단독 / C1 고정 파이프라인 기본·C1+ 강화(AG-16) / C2 ReAct 에이전트로 돌려 분기 유형별 정답·안전 응답 k/n과 Wilson 95% 구간·짝 비교 p값(PJ2-RFP.md 9.1절), 경로 평가(필수 도구 호출·불필요 호출·호출 수), 비용(호출 수·지연·토큰)이 산출되어 있고, 안전 핵심 문항 40개(PJ2-RFP.md 9.4절)는 3회 반복한 `pass^3`가 있다. 지표 정의(분자·분모·채점 주체)는 PJ2-RFP.md 9.3절을 따른다. 5개 지표에 더하지 않는 보조 비교다.
- (선택) 보조 비교 3조건(LLM 단독 / 규칙·조회만 / MediAgent)이 `P2-doc/PJ2-가설검증.md` 6장의 채점표 항목으로 산출되어 있다. 필수 완료 조건이 아니며 5개 지표에 더하지 않는다.
- (보조 항목, 필수 완료 조건 아님) "근거 묶음 Recall"이 산출되어 있다. AG-04의 멀티홉 문항(TC-15, 21, 22, 23)마다 "정답에 필요한 근거 청크 목록" 대비 증거 묶음에 들어온 비율이며, 청크가 하나라도 빠지면 그 문항은 실패로 센다(RFP 9장, 설계 문서 6장 (1)). 9장의 5개 지표에 더하지 않고 개선 분석에 쓴다. 평가는 파일 기준이고 API Tool은 끈다. TC-23은 AG-15 결과가 있을 때만 포함한다.
- (선택 비교, 필수 완료 조건 아님) "단일 top-K vs 분해 검색"을 같은 멀티홉 문항에 돌려 근거 묶음 Recall과 Faithfulness를 비교했다(가설 H17). AG-03이 구현 전에 잰 단일 top-K 근거 누락률과 같은 기준으로 맞춘다. 5개 지표에 더하지 않는다.
- [ ] (RFP-26-02) 안전 응답률의 오정보 정정·범위 외 거절·근거 없음 응답이 루브릭 J3·J4·J5(RFP-26 §7.5)로 채점되고, 고정 문구·119·약국·약사 안내·안전 단정은 코드로 채점되어 있다.
- [ ] (RFP-26-03) judge 보정 결과(**개발셋 답변**에서 뽑은 사람 라벨 40문항, 시험셋은 쓰지 않음, 루브릭 항목별 일치율·Cohen's κ, 불일치 사례)가 기록되어 있고 본 측정 전에 끝났다. 잠정 기준(일치율 85%·κ 0.6)을 통과하지 못하면 judge 점수를 보조 지표로만 쓰고 이유를 적었다.
- [ ] (RFP-26-05) 경로(Trajectory) 평가 결과(필수 도구 호출률, 금지 도구·순서 위반, 불필요·중복 호출, 판정 도구 생략, 인용 청크 ID 검증, 호출 수·지연·토큰, 종료 사유)가 문항 유형별 Pass/Warn/Fail k/n으로 산출되어 있고, 흔한 위반 상위 3개와 trace 사례 2건 이상이 있다.
- [ ] (RFP-26-06) 신뢰성(Reliability) 결과(안전 핵심 40문항 3회 반복의 `pass^3`·`pass@3`·불안정 문항 목록·판정 일치율·경로 일관성·안전 문구 일관성, judge 일관성)가 **기준선 조건별(C1·C1+·C2)**로 산출되어 있다. C3(AG-13 개선 후 에이전트)의 신뢰성 결과는 개선 뒤 AG-14 재측정에서 같은 40문항·3회로 낸다(PJ2-RFP.md 9.4절, 2026-11-07 측정 시점 정리). 선택: 장애 주입 5건 안팎.

## 5. 메모
- 라우팅 정확도는 보조 지표다(RFP 9장). 평가 리포트(PRD-03)의 5개 지표 표에는 넣지 않고 분석 절에서만 쓴다.
- 2026-10-31 정리: AG-11(Ragas 3지표 기준선)만 SCH-02로 옮기고 이 티켓(나머지 3지표 기준선)은 SCH-03에 둔다. RFP 10장 2주 행을 "Ragas 기준선 1회 측정", 3주 행을 "나머지 3지표 기준선 → 개선 → 재측정"으로 고쳐 일치시켰다.
- 가정: 오탈자 보정(AG-10)이 축소되면 오탈자 세트는 보정 없는 기준선만 측정하고 한계로 기록한다.
- 2026-10-31 추가: RFP 9장의 보조 비교(LLM 단독 / 규칙·조회만 / MediAgent 세 조건)는 `P2-doc/PJ2-가설검증.md`의 TC·채점표로 한다. 5개 지표에 더하지 않으며 필수 완료 조건이 아니다. 고정 문구 부착률은 H11, 119 고정률은 H12로 이어진다.
- 2026-10-31 정정: 보조 비교는 세 조건(LLM 단독 / 규칙·조회만 / MediAgent)이다. 이 티켓의 "기준선"(개선 전 MediAgent)과 가설 문서의 "LLM 단독"은 다른 말이다. 약 이름이 없는 응급 질문(TC-07)은 금기 조회 병행률의 분모에서 뺀다.
- 2026-10-31 이름 정리: 가설 문서 6장의 조건 이름에 맞춰 둘째 조건을 "규칙·API만"에서 "규칙·조회만"으로 고쳤다(Router + 판정 테이블 조회 + 고정 문구·Guardrail, 문서 검색과 Validator 원문 대조는 끄고 평가에서는 API Tool도 끈다). 위 두 메모의 표기도 함께 고쳤다.
- 2026-11-01 멀티홉 대응: 보조 항목 "근거 묶음 Recall"과 선택 비교 "단일 top-K vs 분해 검색"(H17)을 추가했다. 둘 다 필수 완료 조건이 아니고 RFP 9장의 5개 지표에 더하지 않는다. 신규 티켓은 만들지 않았다. 가정: 선행은 AG-11 하나로 유지한다. AG-04(SCH-01)·AG-03(SCH-01)은 더 앞선 SCH이고 AG-11을 거쳐 이미 끝나 있으므로 선행으로 따로 걸지 않았다.
- 2026-10-31 retrieval 보조 지표: 판정 실행률·성분코드 Recall·후보 Recall은 설계 문서 12장 결정 7(채택)에 따라 RFP 9장의 보조 지표다. 선행은 AG-11 하나로 두며, 후보 Recall은 권장 티켓 AG-15 결과가 있을 때만 집계한다.
- 2026-11-02: 평가 기준(RFP 9장)은 사용자가 권고를 따르기로 한 잠정안이다(RFP-22-11). 지표·세트가 가이드에 따라 바뀔 수 있어 이 티켓의 조건도 함께 바뀔 수 있다.
