## 1. 이슈
RFP 9장의 나머지 세 지표를 측정한다. 오탈자 견고성은 정상 대비 하락 폭, 안전 응답률은 범위 외·오정보 세트에서 적절히 거절·정정한 비율, 금기 판정 정답률은 정상 세트 중 병용·연령·임부 금기 질문(금기등급 M 성분 포함)에서 판정이 정답 근거와 일치한 비율이다.

## 2. 완료 조건
- [ ] 오탈자 세트와 대응 정상 세트의 정답률 차이가 산출되어 있다.
- [ ] 범위 외·오정보 세트의 안전 응답률이 산출되어 있다.
- [ ] 판정 기준(무엇을 안전 응답으로 보는지)이 문서화되어 있다.
- [ ] 병용·연령·임부 금기 판정 질문의 정답률이 산출되어 있고 금기등급 M 성분 질문이 포함되어 있다.
- [ ] "금기 목록에 없는 약" 질문에서 고정 문구("안전하다는 뜻이 아님")와 약국·약사 확인 안내가 붙은 비율이 산출되어 있다.
- [ ] 응급 상황 질문에서 119 안내가 맨 위에 있고 금기 조회도 함께 이루어진 비율이 산출되어 있다.
- [ ] 보조 지표로 라우팅 정확도(= 도구 선택 정확도: `model`이 질문에 맞는 필수 도구를 골랐는지의 비율, Router 분기가 아님)가 산출되어 있다. 9장의 5개 지표에 더하지 않고 개선 분석(AG-13)에 쓴다.
- [ ] 보조 항목으로 retrieval 보조 지표가 산출되어 있다(RFP 9장, 5.1절 (3) 역할 A·B). 판정 실행률(질문 중 판정 테이블 조회까지 도달한 비율), 성분코드 Recall(약 이름 질문에서 정답 성분코드가 후보에 드는 비율), 후보 Recall(열린 질문에서 자동 정답 세트 대비, AG-15 결과가 있을 때). 9장의 5개 지표에 더하지 않고 개선 분석에 쓴다. 평가는 파일 기준이고 API Tool은 끈다.
- [ ] **(필수, RFP-23)** **시험셋**(RFP-26-04)을 C0 LLM 단독 / C1 고정 파이프라인 기본·C1+ 강화(AG-16) / C2 ReAct 에이전트로 돌려 분기 유형별 정답·안전 응답 k/n과 Wilson 95% 구간·짝 비교 p값(PJ2-RFP.md 9.1절), 경로 평가(필수 도구 호출·불필요 호출·호출 수), 비용(호출 수·지연·토큰)이 산출되어 있고, 안전 핵심 문항 40개(PJ2-RFP.md 9.4절)는 3회 반복(본 측정 1회 + 추가 2회 실행, RFP-35-09 A)한 `pass^3`가 있다. 지표 정의(분자·분모·채점 주체)는 PJ2-RFP.md 9.3절을 따른다. 5개 지표에 더하지 않는 보조 비교다.
- (선택) 보조 비교 3조건(LLM 단독 / 규칙·조회만 / MediAgent)이 `P2-doc/PJ2-가설검증.md` 6장의 채점표 항목으로 산출되어 있다. 필수 완료 조건이 아니며 5개 지표에 더하지 않는다.
- (보조 항목, 필수 완료 조건 아님) "근거 묶음 Recall"이 산출되어 있다. AG-04의 멀티홉 문항(TC-15, 21, 22, 23)마다 "정답에 필요한 근거 청크 목록" 대비 증거 묶음에 들어온 비율이며, 청크가 하나라도 빠지면 그 문항은 실패로 센다(RFP 9장, 설계 문서 6장 (1)). 9장의 5개 지표에 더하지 않고 개선 분석에 쓴다. 평가는 파일 기준이고 API Tool은 끈다. TC-23은 AG-15 결과가 있을 때만 포함한다.
- (선택 비교, 필수 완료 조건 아님) "단일 top-K vs 분해 검색"을 같은 멀티홉 문항에 돌려 근거 묶음 Recall과 Faithfulness를 비교했다(가설 H17). AG-03이 구현 전에 잰 단일 top-K 근거 누락률과 같은 기준으로 맞춘다. 5개 지표에 더하지 않는다.
