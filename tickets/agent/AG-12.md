## 이슈
RFP 9장의 나머지 세 지표를 측정한다. 오탈자 견고성은 정상 대비 하락 폭, 안전 응답률은 범위 외·오정보 세트에서 적절히 거절·정정한 비율, 금기 판정 정답률은 정상 세트 중 병용·연령·임부 금기 질문(금기등급 M 성분 포함)에서 판정이 정답 근거와 일치한 비율이다.

## 완료 조건
- [ ] 오탈자 세트와 대응 정상 세트의 정답률 차이가 산출되어 있다.
- [ ] 범위 외·오정보 세트의 안전 응답률이 산출되어 있다.
- [ ] 판정 기준(무엇을 안전 응답으로 보는지)이 문서화되어 있다.
- [ ] 병용·연령·임부 금기 판정 질문의 정답률이 산출되어 있고 금기등급 M 성분 질문이 포함되어 있다.
- [ ] "금기 목록에 없는 약" 질문에서 고정 문구("안전하다는 뜻이 아님")와 약국·약사 확인 안내가 붙은 비율이 산출되어 있다.
- [ ] 응급 상황 질문에서 119 안내가 맨 위에 있고 금기 조회도 함께 이루어진 비율이 산출되어 있다.
- [ ] 보조 지표로 라우팅 정확도(질문에 맞는 도구를 골랐는지의 비율)가 산출되어 있다. 9장의 5개 지표에 더하지 않고 개선 분석(AG-13)에 쓴다.
- [ ] 보조 항목으로 retrieval 보조 지표가 산출되어 있다(RFP 9장, 5.1절 (3) 역할 A·B). 판정 실행률(질문 중 판정 테이블 조회까지 도달한 비율), 성분코드 Recall(약 이름 질문에서 정답 성분코드가 후보에 드는 비율), 후보 Recall(열린 질문에서 자동 정답 세트 대비, AG-15 결과가 있을 때). 9장의 5개 지표에 더하지 않고 개선 분석에 쓴다. 평가는 파일 기준이고 API Tool은 끈다.
- (선택) 보조 비교 3조건(LLM 단독 / 규칙·조회만 / MediAgent)이 `P2-doc/PJ2-가설검증.md` 6장의 채점표 항목으로 산출되어 있다. 필수 완료 조건이 아니며 5개 지표에 더하지 않는다.

## 하위 작업

- [ ] 라우팅 정확도 계산(AG-04의 기대 경로와 실제 경로 비교)
- [ ] retrieval 보조 지표 계산(판정 실행률, 성분코드 Recall, 후보 Recall)
- [ ] 3조건 비교 실행(LLM 단독 / 규칙·조회만 / MediAgent)
- [ ] 고정 문구·119 안내 유무 판정 기준 추가(코드 검사로 판정)
- [ ] 실행·집계

## 메모
- 라우팅 정확도는 보조 지표다(RFP 9장). 평가 리포트(PRD-03)의 5개 지표 표에는 넣지 않고 분석 절에서만 쓴다.
- 2026-10-31 정리: AG-11(Ragas 3지표 기준선)만 SCH-02로 옮기고 이 티켓(나머지 3지표 기준선)은 SCH-03에 둔다. RFP 10장 2주 행을 "Ragas 기준선 1회 측정", 3주 행을 "나머지 3지표 기준선 → 개선 → 재측정"으로 고쳐 일치시켰다.
- 가정: 오탈자 보정(AG-10)이 축소되면 오탈자 세트는 보정 없는 기준선만 측정하고 한계로 기록한다.
- 2026-10-31 추가: RFP 9장의 보조 비교(LLM 단독 / 규칙·조회만 / MediAgent 세 조건)는 `P2-doc/PJ2-가설검증.md`의 TC·채점표로 한다. 5개 지표에 더하지 않으며 필수 완료 조건이 아니다. 고정 문구 부착률은 H11, 119 고정률은 H12로 이어진다.
- 2026-10-31 정정: 보조 비교는 세 조건(LLM 단독 / 규칙·조회만 / MediAgent)이다. 이 티켓의 "기준선"(개선 전 MediAgent)과 가설 문서의 "LLM 단독"은 다른 말이다. 약 이름이 없는 응급 질문(TC-07)은 금기 조회 병행률의 분모에서 뺀다.
- 2026-10-31 이름 정리: 가설 문서 6장의 조건 이름에 맞춰 둘째 조건을 "규칙·API만"에서 "규칙·조회만"으로 고쳤다(Router + 판정 테이블 조회 + 고정 문구·Guardrail, 문서 검색과 Validator 원문 대조는 끄고 평가에서는 API Tool도 끈다). 위 두 메모의 표기도 함께 고쳤다.
- 2026-10-31 retrieval 보조 지표: 판정 실행률·성분코드 Recall·후보 Recall은 설계 문서 12장 결정 7(채택)에 따라 RFP 9장의 보조 지표다. 선행은 AG-11 하나로 두며, 후보 Recall은 권장 티켓 AG-15 결과가 있을 때만 집계한다.
