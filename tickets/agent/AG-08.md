## 이슈
RFP FR-06: 진단·처방 금지 문구, 응급 키워드가 있으면 119 안내를 맨 위에 고정하되 금기 조회는 막지 않음, 범위 외 거절. 조회 결과에 금기가 없어도 안전하다고 말하지 않는 고정 문구와 "근처 약국·약사에게 확인" 안내를 모든 답변에 코드로 붙인다(프롬프트가 아니라 코드). 7장 고지 문구도 모든 응답에 붙인다. 범위 제외 항목은 진단, 처방, 복용량 결정, 개인 의료기록 처리다(4장).

8장 구조도의 "응급 키워드: Guardrail이 119 안내를 답변 맨 위에 고정하고, 위 경로는 막지 않고 병행 실행한다"를 구현한다. **응급 키워드 감지는 이 티켓의 코드 규칙 한 곳에서만 한다.** 감지 결과는 상태의 `emergency`에 기록하고 Router(AG-05)는 이 신호를 읽기만 한다.

규칙 구현 방식은 항목마다 (코드) / (프롬프트)로 표기한다. 고정 문구는 프롬프트가 아니라 코드가 맡는다.

## 완료 조건
- [ ] (코드) 응급 키워드 질문의 응답은 119 안내가 맨 위에 고정되고, 병용·연령·임부 금기 조회와 답변 생성은 막지 않고 함께 수행된다.
- [ ] (코드) 응급 키워드 감지가 이 티켓의 한 함수에만 있고, Router 등 다른 노드에 키워드 목록이 없음을 코드 검색으로 확인했다.
- [ ] (코드) 금기가 조회되지 않은 응답에도 "금기 목록에 없다는 것이 안전하다는 뜻이 아님" 고정 문구와 "근처 약국·약사에게 확인" 안내가 코드로 붙고, LLM 출력 변경으로 빠지지 않음을 테스트로 확인했다.
- [ ] 119와 약국·약사 안내 외의 응급 지침·연락처는 RFP-19에서 공식 출처를 확인한 것만 쓴다. RFP-19를 끝내지 못했으면 119와 약국·약사 안내만 쓴다.
- [ ] (프롬프트 + 코드 판별) 진단·처방·복용량 결정 요청이 거절되고 근거 기반 정보 안내로 이어진다.
- [ ] (프롬프트 + 코드 판별) 범위 외 질문이 거절된다.
- [ ] (코드) 모든 응답 본문에 고지 문구가 포함된다.
- [ ] 각 유형 5건 이상 테스트가 통과한다.

- 응급(FR-06)은 필수라 범위 축소 대상이 아니다(RFP 12장).
- 2026-10-31 추가: 응급 키워드에 과량 섭취 표현(예: "한 통 다 먹었어")과 임신 중 호흡곤란 같은 표현을 포함해 `P2-doc/PJ2-가설검증.md`의 TC-07·TC-11로 시험한다. 이 둘은 119 안내를 맨 위에 고정하고, 약 이름이 있으면 금기 조회를 막지 않는다. 과량 대처 지침은 RFP-19 확인 전에는 만들지 않는다.
