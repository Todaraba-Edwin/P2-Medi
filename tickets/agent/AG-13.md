## 1. 이슈
RFP 10장 3주차 "측정 → 개선 → 재측정". 기준선에서 낮은 지표의 원인을 실패 사례로 분석해 개선한다(예: 청킹, 검색 k·필터, 프롬프트, Router 규칙).

## 2. 완료 조건
- [ ] 실패 사례 상위 원인과 선택한 개선 항목이 `메모`에 기록되어 있다.
- [ ] 개선 변경이 커밋으로 분리되어 있다.
- [ ] 기준선 실패 사례에 대응하는 (개선) 조건만 구현했고, 구현하지 않은 (개선) 조건은 이유(기준선에서 실패 없음)를 `메모`에 적었다.
- [ ] 평가 세트는 수정하지 않았다(재현성).

## 3. 하위 작업
- [ ] 실패 사례 분석
- [ ] 개선 적용

## 4. 관련
- 선행: AG-11, AG-12
- 관련 문서: `P2-doc/PJ2-RFP.md` 7장, 9장, 10장

## 5. 메모
- 2026-11-02 계획 변경(사용자가 RFP-22 §13 P1~P4 승인): 이 티켓이 (개선) 표시 조건(AG-03 누락률 측정·분해 검색·증거 묶음, AG-05 주장 유형 목록, AG-06 증거 묶음·map-reduce, AG-07 근거 계층·누락 검사)과 종료 sensor·관련성 판정(grade)·LangGraph 재조립(RFP-22-03)을 실패 사례 순으로 구현하는 곳이다. 기준선 실패가 없는 항목은 만들지 않는다.
- 2026-11-02 RFP-22-04 결정(A): `Send`, time travel, 멀티에이전트, 질문 재작성 루프는 기준선 실패가 확인되기 전까지 만들지 않는다. 개선은 기준선 실패에 대응하는 (개선) 조건만 구현한다.
