## 1. 이슈
ISSUE-003(2026-11-09 사용자 지적, 질문 "엄마가 이지렉트정을 드시는데 콜드-에스 같이 드려도 돼요?")은 근거 상세의 규칙 부재를 짚은 이슈다. 이미지(`tickets/issues/ISSUE-003.png`)를 읽은 결과: 오른쪽 "근거 상세" 패널에서 "판정 · DUR 병용금기"는 흰 박스인데 "사유 원문"은 맨 글이고, "허가사항"에는 박스가 2개(이지렉트정은 "원문을 가져오지 못했어요", 타이레놀콜드-에스정은 인용)이며, "출처"는 행이 아닌 한 문단이었다. PRD-11이 구역·출처 표·미확보 고지를 정했고 FE-02-05 A(2026-11-18)가 "구역마다 권고 박스 1개 + 미확보 목록"으로 정리했다. 이번에는 그 전후(`ISSUE-003-after.png`는 로컬 `data/mock/fe-issue-shots/`)를 다시 눈으로 확인한다.
- 마감: 발표(27일) 전, **오늘 W3-1(2026-11-23) 오후까지**.
- 사용자 눈 확인이 몫이고 평가 동결 경로(`backend/app/agent`·`tools`)는 고치지 않는다.

## 2. 무엇을 보는가
- 대상: 근거 상세 패널의 허가사항 구역(권고 박스 1개 + 미확보 목록), 사유 원문·출처 행 표
- 관련: [PRD-11](../doc/PRD-11.md) §6.7·§8 ①~⑫, [FE-02](FE-02.md) §3 2.1-3 행·결정 FE-02-05 A, [FE-08](FE-08.md) 2.1-3("걸리는 점" → FE-02-05), [FE-11](FE-11.md)(결과 화면 개편, 구역 렌더 5b는 백로그)
- 알려진 차이(서버 #7·#8, 백로그): 미확보 근거 표지에 출처 종류 글자가 없고 출처 표에 그 자료 행이 없다. 실패가 아니라 "부분"으로 기록
- 옛 문구 "원문을 가져오지 못했어요"는 프런트 `src`·`e2e`에서 0건이다(fe02-audit 2026-11-22)

## 3. 재현 방법
- 입력(실응답): "엄마가 이지렉트정을 드시는데 콜드-에스 같이 드려도 돼요?" — ISSUE-003 원 질문(`tickets/doc/PRD-11.md` §1). 병용금기 결과가 나와야 한다
- 입력(MSW 목): `mock:미확보원인`(미확보 원인 표본, `frontend/src/mocks/handlers.ts:30`), `mock:등급정의미확보`(`:32`). `FE-08.md:153`이 ISSUE-003의 직접 입력으로 `mock:미확보원인` 또는 근거 상세 표본 `missing`을 적었다
- 절차: 질문 → 결과 카드 → "근거 상세 열기 · 성분코드·출처" 클릭 → 패널에서 "허가사항" 구역과 "출처" 구역 확인
- 나와야 할 화면: 허가사항 구역에 같은 문장이 박스마다 반복되지 않고 **권고 박스 1개** 아래에 미확보 항목 목록, 출처는 행으로 나뉜 표

## 4. 합격 기준
- [ ] 허가사항 구역의 약사 확인 권고가 **1개**이고 3번 반복되지 않는다(FE-02-05 A)
- [ ] "원문을 가져오지 못했어요" 문구가 없다
- [ ] 미확보 항목이 권고 박스 아래 목록으로 있다
- [ ] 출처가 한 문단이 아니라 행으로 나뉜 표다(PRD-11-02)
- [ ] 사유 원문·판정 구역의 소제목과 흰 박스 규칙이 일관된다(PRD-11 §8)
- [ ] 이지렉트정이 전문의약품이라 설명(e약은요)이 없다는 한계가 숨겨지지 않고 고지된다(사용자 방침 2026-11-09, PRD-11-03)- [ ] 안전 표시: "안전하다"는 표현 없음, 복용 여부·용량을 정해 주는 문장 없음, 병아리 마스코트가 금기·고정 문구 영역에 없음
- [ ] 법적 고지 한 줄("공공데이터 기반 정보 제공이며 진단·처방이 아님 · 금기 목록에 없다는 것이 안전하다는 뜻이 아님 · 요양기관의 DUR 점검을 대체하지 않음", `backend/app/agent/fixed_phrases.py:30-35`)이 보인다
- [ ] 화면 폭 393·1280, 라이트·다크 모두 글자가 잘리거나 가로 스크롤이 없다
- [ ] 접근성: 키보드(Tab·Enter·Esc)로 조작되고 읽기 순서가 화면 순서와 같다
