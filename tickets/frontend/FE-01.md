## 1. 이슈
질문을 입력하고 답변을 보는 최소 채팅 화면. RFP 3장 목표 1 "끝단 동작"과 데모의 기반이다.

## 2. 완료 조건
- [ ] 질문 입력 → `/chat` 호출 → 답변 표시가 동작한다.
- [ ] 로딩·오류 상태가 표시된다.
- [ ] (RFP-24-04) 휴대폰 화면 폭(360px 안팎)에서 질문 입력·답변 요약·근거 상세 펼침이 가로 스크롤 없이 쓰인다.
- [ ] (PRD-06-02) 병아리 마스코트는 시작·로딩·빈 상태·오류 같은 보조 자리에만 쓰고(작은 크기의 되묻기 카드 가능), 응급(119)·금기 결과·"금기 목록에 없음"·고정 문구 영역에는 쓰지 않는다. 화면의 표시 이름은 Can I Biyak(한글 삐약 병기)이다(PRD-06-01).
- [ ] (PRD-01-02) 응급이면 119 안내가 답변이 오기 전에 맨 위에 먼저 보이고, 일반 질문은 진행 상태(약 찾는 중·금기 확인 중·근거 찾는 중)가 표시된다.
