## 1. 이슈
사용자 요구 원문(2026-11-23): "원래는 로그인 되어도 선택한 약관에 대해서는 볼 수 있었어야 함. 프로필 > 이용약관 등이 보여지도록. 게스트라 하여도 현재 약관에 대한 부분이 화면에서 사라짐. 내용 반영 후 로그인·게스트 상태에서 약관 확인. 게스트의 약관과 회원의 약관에 차이가 있어 2가지 타입의 약관이 필요."
- 로그인한 사용자는 프로필에서 이용약관 등 문서를 다시 볼 수 있어야 하고, 게스트도 시작 화면에서 약관 고지가 보여야 한다.
- 구현은 프런트 완료·병합 진행 중(2026-11-23, 단위 1718·e2e 456 통과). 진입점은 계정 메뉴 `약관·정책` 행 + 설정 묶음(게스트·회원 모두, 읽기 전용 펼침, 서버 값 그대로, 서버에 없는 종류는 숨김). **게스트 약관이 사라진 원인**: 커밋 `556c48b`(PRD-17-10 A, 11-22)가 시작 화면 외부 AI 고지 `ExternalAiNotice`를 의도적 중복 제거로 삭제(`AppShell.tsx:361-363` 주석). 구조적으로 약관 본문 진입점이 계정 모달 동의 단계(`ConsentStep.tsx`) 하나뿐이고 게스트는 `accountStore.open()`이 로그인부터 시작(`stores/account.ts:300`)해 열람할 수 없었다. 처리방침은 공통 `privacy_policy`(PRD-17-23 A). 게스트판 문서 종류는 PRD-17-22 A(별도 `terms_guest`)로 확정(2026-11-23). 서버 게시는 BE-11 ③(원문 승인 뒤)이라 그 전에는 항목을 숨긴다.

## 2. 완료 조건
- [ ] 로그인 상태에서 프로필 메뉴에서 이용약관·처리방침 등 문서를 열람할 수 있다(`/legal/*` 응답 표시).
- [ ] 게스트 상태에서 약관 열람 진입점이 있고 게스트 시작 고지(사라진 부분)가 한 번만 보인다.
- [ ] 서버에 해당 `doc_type`이 없으면(예: `terms_guest` 미게시) 그 항목을 숨기고 오류 화면을 내지 않는다.
- [x] 새로 추가·변경하는 사용자 보이는 글자 목록을 만들어 사용자 승인을 받는다: 새 글자 `약관·정책` 승인(2026-11-23).
- [ ] 로그인·게스트 두 상태에서 사용자가 약관 화면을 눈으로 확인한다(구 Recap 3).
