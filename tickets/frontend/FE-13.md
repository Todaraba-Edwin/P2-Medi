## 1. 이슈
RFP-27 조건 2("FE-02가 done이고 되묻기 카드가 후보 표와 질문 1개로 표시됨을 화면에서 확인")는 사용자가 화면을 직접 보아야 닫힌다. `fe02-audit.md`가 FE-02 `:43`을 "부분"으로 판정했다(프런트 카드·질문 1개·가부 미표시·마스코트 규칙은 충족, 후보 표의 사용법 첫 문장·DUR 수록 열은 서버 #1 때문에 응답에 없음).
- 마감: 발표(27일) 전, **오늘 W3-1(2026-11-23) 오후까지**.
- 사용자 눈 확인이 몫이고 평가 동결 경로(`backend/app/agent`·`tools`)는 고치지 않는다.

## 2. 무엇을 보는가
- 대상: 약 이름이 여러 제품으로 갈릴 때 나오는 **되묻기 카드**(후보 목록 + 질문 1개), 한 번에 여러 약을 되묻는 묶음 카드 포함
- 관련: [RFP-27](../doc/RFP-27.md) §2 조건 2, [FE-02](FE-02.md) §3 `:43`, [FE-10](FE-10.md)(2열·캡슐 표지), FE-09(여러 약 되묻기), PRD-01-01, PRD-14
- 이미 확인된 것: FE-10은 2026-11-22 사용자가 실제 백엔드 캡처·VoiceOver 확인을 끝냈다(FE-10 §5). 이번에는 **RFP-27의 "후보 표 + 질문 1개 + 가부 미언급"** 조건 관점으로만 본다
- 알려진 미충족: 후보 표의 "사용법 첫 문장"·"DUR 수록" 열은 서버 `Candidate`(`backend/app/api/schemas.py:361-369`)에 칸이 없어 비어 있다(서버 #1, 백로그). 이 열이 없는 것은 실패가 아니라 "부분"으로 기록한다

## 3. 재현 방법
- 환경: 개발 서버, 게스트 또는 로그인 모두 가능(프로필 영향 없음). 실제 백엔드가 떠 있으면 실응답, 아니면 MSW 목
- **입력 A(실응답)**: "뉴론틴 먹어도 돼요?" 또는 "그리피드 아이한테 줘도 되나요?" — 개발셋 모호 문항(`evaluation/eval_set/dev_set.jsonl:76-77`, expected `clarify`, 필수 요소 `CANDIDATES_SHOWN`·`ONE_QUESTION`·`NO_VERDICT`). 시험셋은 열람하지 않는다. RFP-27 §2에 예시로 적힌 "타이레놀 먹어도 돼요?"도 쓸 수 있다
- **입력 B(MSW 목, 백엔드 없이)**: `mock:되묻기 합성 질문`(한 약), `mock:되묻기여러 합성 질문`(여러 약 묶음). 근거: `frontend/src/mocks/mocking.test.ts:46-52`, `frontend/e2e/msw.spec.ts:29·64`. 목은 `NEXT_PUBLIC_API_MOCKING=enabled`일 때만 동작
- 절차: 질문 전송 → 되묻기 카드 확인 → 후보 하나 선택(라디오) → 다음 단계로 재질문되어 결과가 나오는지 확인(재질문은 2단계, FE-01-23 A)
- 나와야 할 화면: 후보 카드 여러 개 + **질문 1개**, 판정·가부 문구 없음, 여러 약이면 약마다 묶음(1024px 이상 2열)
