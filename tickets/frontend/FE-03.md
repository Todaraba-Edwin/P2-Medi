## 1. 이슈
RFP 11장 "데모 (영상 또는 실행 화면)". 정상 조회, 병용금기, 문서 검색, 오탈자, 응급, 범위 외, 근거 없음을 보여주는 시나리오를 만든다.

## 2. 완료 조건
- [ ] 시나리오 문서에 질문 7종 이상과 기대 응답 유형이 있다.
- [ ] 시나리오에 "금기 목록에 없는 약" 질문(고정 문구와 약국·약사 안내 노출)과 응급 질문(119 안내 최상단 + 금기 조회 병행)이 포함되어 있다.
- [ ] 데모 화면에서 쉬운 요약이 먼저 보이고 근거 상세를 펼치는 장면이 있다.
- [ ] 영상 파일 또는 화면 캡처가 저장소/발표 자료에서 접근 가능한 위치에 있다.

## 3. 하위 작업
- [ ] 시나리오 작성(금기 없는 약·응급·근거 펼침 장면 포함)
- [ ] 녹화·캡처
- [ ] (FE-03-01 A, 2026-11-20) 실제 답변 장면은 **로컬 실서버 실행 화면을 녹화**해 만든다(백엔드는 공개하지 않음, 터널 Recap 52 보류 유지). Vercel 주소(목 데모, BE-13-07 A)는 화면 소개용이고 목 응답은 합성이라 실제 판정·근거로 보이지 않게 한다. 영상·캡처 파일은 로컬 서버를 켠 상태에서 녹화한다

## 4. 관련
- 선행: FE-02
- 관련 문서: `P2-doc/PJ2-RFP.md` 11장

## 5. 메모
- 가정: 오탈자 시나리오는 AG-10이 축소되면 제외한다.
- 2026-11-20 음성 입력은 제외 확정(AG-10-09 A)이라 데모 시나리오에 음성 장면을 넣지 않는다(사진 입력은 필수 기능이라 구현되면 장면에 포함).
