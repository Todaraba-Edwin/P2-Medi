## 1. 이슈
사전에 없는 약 이름이면 서버가 "약을 찾지 못해 확인하지 못함"으로 응답하고 안전하다고 말하지 않아야 한다. 프런트 박스·진입 줄은 구현됐으나(`d518de7`) 서버 `searched`가 자료 이름("식약처 의약품 제품 허가정보" 등, `backend/app/agent/tools/identify_drug.py:23,91`)이라 PRD-14의 "식약처·한국의약품안전관리원 자료" 문구와 다르고(서버 #6), 실제 미식별 응답 화면은 가짜 서버로 만들 수 없어 사용자 눈 확인이 남았다(`fe02-audit.md` `:57`).
- 마감: 발표(27일) 전, **오늘 W3-1(2026-11-23) 오후까지**.
- 사용자 눈 확인이 몫이고 평가 동결 경로(`backend/app/agent`·`tools`)는 고치지 않는다.

## 2. 무엇을 보는가
- 대상: 미식별 결과 카드와 근거 상세의 미식별 박스("찾아본 곳"), 동작 칩
- 관련: [PRD-14](../doc/PRD-14.md) 미식별 박스·§10, [FE-02](FE-02.md) `:57`, AG-08-05·06(고정 문구 원문 승인), [FE-11](FE-11.md) 5a 고지 시험
- 고정 문구(`backend/app/agent/fixed_phrases.py`): `UNIDENTIFIED`(:49)="약을 찾지 못해 확인하지 못함", `UNIDENTIFIED_WHY`(:56)="식약처·한국의약품안전관리원 자료에서 찾지 못했어요", `UNIDENTIFIED_RETRIED`(:57)="표기를 바꿔 한 번 더 찾아봤어요", `UNIDENTIFIED_NEXT`(:58)="봉투나 상자에 적힌 제품명을 그대로 다시 알려 주세요", `UNIDENTIFIED_NOT_SAFE`(:59)="찾지 못했다는 뜻이며 안전하다는 뜻이 아니에요", `UNIDENTIFIED_SUB_LINE`(:61)
- 알려진 차이: "찾아본 곳" 값이 기관 이름이 아닌 자료 이름(서버 #6, BE 상수 교체 약 0.5h, 동결 경로라 백로그)

## 3. 재현 방법
- 입력(MSW 목, 백엔드 없이): `mock:미식별`, `mock:미식별혼합`(`frontend/src/mocks/handlers.ts:48-49`), 픽스처 `frontend/src/mocks/fixtures/responses.ts:374-384`가 위 문구 상수를 그대로 쓴다
- 입력(실응답): 사전에 없는 이름을 지어 낸 약, 예: "가나다엑스정 먹어도 돼요?"(실제 사전에 없는지 확인 필요, 있으면 다른 이름). 근거: UNIDENTIFIED 계열 문구는 미식별 경로에서만 쓰인다(`fixed_phrases.py:49-61`). 시험 근거: `frontend/e2e/flows.spec.ts:586`(코드가 이어지지 않은 줄에서 같은 문구), `:1424-1468`(미식별 결과 동작 칩)
- 절차: 질문 → 결과 카드 문구 확인 → "· 찾아본 곳" 진입 글자 클릭 → 근거 상세의 미식별 박스 확인
- 나와야 할 화면: "약을 찾지 못해 확인하지 못함" + 사유·다시 알려 달라는 안내 + "찾지 못했다는 뜻이며 안전하다는 뜻이 아니에요", 판정 배지 없음

## 4. 합격 기준
- [ ] 결과 카드 줄이 "약을 찾지 못해 확인하지 못함"(고정 문구 원문)이다
- [ ] "찾지 못했다는 뜻이며 안전하다는 뜻이 아니에요"가 보인다
- [ ] "금기 목록에 없음"·"안전" 판정 배지가 없다
- [ ] 다시 알려 달라는 안내("봉투나 상자에 적힌 제품명을 그대로 다시 알려 주세요")가 보인다
- [ ] 미식별 진입 글자에 "· 찾아본 곳"이 붙고, 열면 박스가 열린다. 동작 칩은 결과 쪽에만 있고 근거 상세 박스에는 없다
- [ ] 찾아본 곳이 자료 이름("식약처 의약품 제품 허가정보" 등)인지 기관 이름인지 기록한다(자료 이름이면 서버 #6 "부분")- [ ] 안전 표시: "안전하다"는 표현 없음, 복용 여부·용량을 정해 주는 문장 없음, 병아리 마스코트가 금기·고정 문구 영역에 없음
- [ ] 법적 고지 한 줄("공공데이터 기반 정보 제공이며 진단·처방이 아님 · 금기 목록에 없다는 것이 안전하다는 뜻이 아님 · 요양기관의 DUR 점검을 대체하지 않음", `backend/app/agent/fixed_phrases.py:30-35`)이 보인다
- [ ] 화면 폭 393·1280, 라이트·다크 모두 글자가 잘리거나 가로 스크롤이 없다
- [ ] 접근성: 키보드(Tab·Enter·Esc)로 조작되고 읽기 순서가 화면 순서와 같다
